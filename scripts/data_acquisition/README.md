# Инструменты получения данных (исследовательские)

Скрипты, которыми 27.10.2026 были собраны материалы из `data/sources/`. Они не прошли ревью, не входят в доверенное ядро и сохранены для воспроизводимости и происхождения данных. Ничего из этого не нужно для работы движка.

| Скрипт | Что делает |
|---|---|
| `clean_vtt.py <вход.vtt> <выход.txt>` | Превращает автосубтитры YouTube (VTT) в связный текст с метками времени примерно раз в 30 секунд, убирая дубли скользящего окна |
| `fetch_forum.py <url темы phpBB> <выход.txt>` | Скачивает все страницы темы форума и сохраняет посты (автор, дата, текст) |
| `list_forum.py <выход.tsv> <id раздела>...` | Перечисляет темы разделов форума (раздел, тема, число ответов, заголовок) |
| `parse_tg.py <каталог экспорта> <выход.txt>` | Разбирает HTML-экспорт Telegram Desktop в простой текст |
| `tg_stats.py <чат.txt> <выход.txt>` | Статистика чата: авторы, годы, темы, счётчики ключевых слов |
| `tg_grep.py <чат.txt> <выход.txt> <контекст> <regex>` | Выбирает сообщения по регулярному выражению с соседними |
| `hash_export.py <каталог экспорта>` | Считает агрегатный SHA-256 экспорта (используется в `data/sources/telegram-chat/manifest.json`) |
| `extract_pdf_text.py <вход.pdf> <выход.txt>` | Извлекает текст из PDF (нужен `pypdf`) |

## Замечания по среде (Windows)

- Кириллица в аргументах командной строки PowerShell искажается; регулярные выражения с кириллицей надёжнее хранить в файле скрипта и писать результат в файл в кодировке UTF-8.
- `pypdf` и `yt_dlp` установлены в пользовательский каталог пакетов: запуск `python -I` (изолированный режим) их не видит, обычный `python` видит.
- Субтитры YouTube получены через `python -m yt_dlp --skip-download --write-auto-subs --sub-langs ru-orig --sub-format vtt`; опция `--print` отключает скачивание субтитров.
- Сайт `sciteclibrary.ru` и архив `web.archive.org` недоступны из этой среды (проверено 27.10.2026).
- Экспорт чата содержит имена частных лиц: хранится только в `private/` (вне git).

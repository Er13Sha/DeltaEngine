Дата: 27.10.2026. Код: `adapters/field_lattice/screening.py` (опыт), `delta_science/action.py` (формула, точная арифметика). Данные: `data/experiments/field/screening.json`. Повторить: `python -m adapters.field_lattice.experiments --screening`.

2. «Формулу всего будем использовать из видео» Rek8C322Q5k («Формула мироздания», «Катющик ТВ», 2022; расшифровка `data/sources/video-transcripts/Rek8C322Q5k.ru-auto.txt`).

## Формула из видео

```
W = Q·N                   воздействие = качество × количество
Q = k_пр·c1 / (4π r²)     c1 — базовая интенсивность, k_пр = 1 (однородное пространство), 4πr² — площадь сферы
N = h·S·ρ                 материальный слой: высота × площадь сечения × плотность
F = k_в·N₂·Q·N₁·cos α     сила на воспринимающее тело
```

При C = c1·k_пр/(4π): F = C·N₁·N₂/r². В `delta_science/action.py` π держится символом, поэтому сокращение 4π точное.

| Проверка | Результат |
|---|---|
| Тяготение, c1 = 4πG | C = G ровно (дробь 66743/10¹⁵), сила пары протонов равна G·m_p²/r² без округления |
| Электричество, c1 = 1/ε₀ | C = 1/(4πε₀) = 8,98755179·10⁹, совпадает с табличным k_e до 10⁻¹⁰ |
| Знак | формула даёт величину; направления она не содержит (автор сам отмечает отсутствие обоснования знака «минус», 22:34) |

## Модель D

Пространство пронизано изотропным потоком: с каждого направления приходит импульс I на единицу площади и стерадиан. Тело — шар радиуса r, поглощает долю 1 − e^(−μL) луча с хордой L. Члена притяжения в правиле нет: сила — недостаток импульса лучей, которые прошли через соседнее тело. Интеграл по конусу направлений и сечению тела считается квадратурой Гаусса—Лежандра.

| Опыт | Результат |
|---|---|
| Отрицательный контроль: одно тело в потоке | сила 3·10⁻¹⁶ (ноль квадратуры) |
| Пара тел | притяжение; показатель закона расстояния −2,0001 |
| Формула видео при c1 = 4π·I, N = μ·V | отношение «опыт / формула»: μ = 0,001 → 0,998; 0,01 → 0,985; 0,1 → 0,863; 1 → 0,278; 10 → 0,006; от расстояния не зависит |

**Что это значит для формулы.** В модели D формула видео выводится, а не постулируется: базовая интенсивность c1 — это поток со всех направлений (c1 = 4π·I), закон 1/r² — геометрия сферы, количество N = h·S·ρ — поглощающее вещество тела. Знак тоже получает механизм: поток, который тело *испускает* («надуваем шарик», 12:12), расталкивает (одноимённые в семействе C); поток *извне*, заслонённый соседом, сближает (семейство D).

Граница: N = h·S·ρ верно только для прозрачных тел. Плотное тело не поглощает больше, чем приходит на его сечение, и сила насыщается. Это известное возражение к экранирующей гравитации: в природе сила тяготения пропорциональна массе с точностью лучше 10⁻¹² (проверки принципа эквивалентности: опыты типа Этвёша, лунная лазерная локация), поэтому реальные тела должны быть почти прозрачны для такого потока.

## Одноимённые заряды в потоке

Оба взаимодействия имеют вид F = C·N₁·N₂/r²: отталкивание k·q_A·q_B/r² и притяжение экранированием G_s·m_A·m_B/r². Оба убывают одинаково, поэтому:

**одноимённые притягиваются тогда и только тогда, когда G_s·m_A·m_B > k·q_A·q_B — на любом расстоянии**, а иначе отталкиваются на любом расстоянии. Предложение заказчика в модели работает, но только для тел с малым отношением заряда к массе.

Для реальных частиц (CODATA 2018): у пары протонов электрическое отталкивание в 1,24·10³⁶ раз сильнее тяготения. Притяжение требует q/m < 8,6·10⁻¹¹ Кл/кг, у протона 9,6·10⁷ Кл/кг. Поэтому одноимённые элементарные заряды в природе отталкиваются, а заряженные пылинки и планеты (q/m мало) притягиваются, как и наблюдается.

## Проверка C6: торможение и нагрев

Код: `adapters/field_lattice/drag.py`, данные: `data/experiments/field/drag.json`, повторить: `python -m adapters.field_lattice.experiments --drag`.

Поток D состоит из носителей массы m со скоростью u и плотностью n, тогда I = n·m·u²/(4π). Из притяжения F = I·N_A·N_B/d² следует G = I/λ², где λ = M/N — масса тела на единицу поглощающего сечения. Тело, которое движется со скоростью v, встречает спереди больше носителей, чем сзади, и поглощает их энергию:

```
торможение   a = (4π/3)·G·λ·v/u
нагрев       P/M = 2π·G·λ·u
```

| Опыт | Результат |
|---|---|
| Тело в покое | торможения нет (−1·10⁻¹⁷, ноль квадратуры) |
| Множитель торможения K(v/u) | −v/(3u): отношение 0,99999998 при v/u = 10⁻⁴ |
| Переизлучение носителей со скоростью β·u | тяготение умножается на (1 − β): β = 0 → 1,000; 0,5 → 0,500; 1 → 0,000 (μ = 0,01 и μ = 1) |

**Земля**, самые мягкие допущения: она хотя бы не непрозрачна для потока (μ·2R ≤ 1, отсюда λ ≥ 7,0·10¹⁰ кг/м²) и её орбита не затухла за 4,54 млрд лет (допуск — вся скорость орбиты).

| Величина | Значение |
|---|---|
| Если носители летят со скоростью света | Земля остановилась бы на орбите за 177 суток; нагрев 8,8·10⁹ Вт/кг |
| Скорость носителей, чтобы орбита выжила | u ≥ 2,8·10¹⁸ м/с = 9,4·10⁹ c |
| Нагрев при этом (от u не зависит: (8π²/3)·G²·λ²·t) | ≥ 8,3·10¹⁹ Вт/кг, вся Земля ≥ 5·10⁴⁴ Вт |
| Наблюдаемый поток тепла из недр | 4,7·10¹³ Вт — в 10³¹ раз меньше |
| Равновесная температура поверхности при таком нагреве | 2·10⁹ К |
| Если энергия идёт не в тепло, а в массу (dM/dt = P/c²) | масса Земли удваивалась бы за 1 мс |

**Вывод.** Три выхода закрыты: поглощать носители (нагрев на 31 порядок больше наблюдаемого), переизлучать их (тяготение пропадает ровно настолько, насколько переизлучение упругое), набирать массу (удвоение за миллисекунду). Механизм D отклонён как объяснение тяготения — к тому же выводу пришли Максвелл (1875) и Пуанкаре (1908). Носители считались нерелятивистскими; для u → c множители меняются на порядок единицы, на 31 порядок это не влияет.

Что остаётся в силе:

- **формула воздействия** W = Q·N: она равна законам Ньютона и Кулона и от механизма не зависит;
- **условие для одноимённых зарядов** G·m_A·m_B > k·q_A·q_B: оно верно для любого тяготения вида 1/r², как бы оно ни возникало; для протонов оно не выполняется в 1,24·10³⁶ раз.

Открытым остаётся вопрос, откуда у тяготения знак «притяжение», — экранирование изотропного потока на него ответить не может.

## Не проверено

- Связь D с частицами семейства C на решётке: здесь тела — заданные шары, а не уплотнения поля.
- Магнитные и ядерные силы в одной схеме — проверены в [track-e-unified.md](track-e-unified.md): магнетизм выводится при конечной скорости передачи, ядерные силы — при затухающем коэффициенте передачи; слабые не проверены.

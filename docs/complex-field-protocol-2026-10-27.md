# Протокол: комплексное поле, предварительная вариационная проверка

Записан до расчёта. Область результата: `scope = model`. Это самостоятельная проверка возможности связанного сгустка, а не продолжение чисел прежнего расчёта: его уравнения, единицы и параметры в этой копии не найдены.

## Модель и наблюдаемые

В трёх пространственных измерениях, в безразмерных единицах, используем комплексное поле с глобальной U(1)-симметрией. Для поля `φ = f(r) exp(i ωt)`, действительного `f`, энергия и сохраняющийся заряд заданы нормировкой

`E = ∫ [½ |∂tφ|² + ½ |∇φ|² + U(|φ|)] d³x`, `Q = ω ∫ f² d³x`,

`U(f) = ½ f² − ¼ f⁴ + ⅙ f⁶`. Масса малого свободного возбуждения равна `m = 1`. Потенциал выбран как пример и содержит привлекательное нелинейное самодействие. Он не удовлетворяет условию отсутствия прямого притяжения для проверки H2, поэтому результат не проверяет экранирование.

Пробный профиль — `f(r) = A exp(−r²/(2R²))`. Для фиксированного положительного Q и I₂ = ∫f², частота `ω = Q/I₂`, энергия

`E = Q²/(2 I₂) + 3 I₂/(4 R²) + ½ I₂ − ¼ I₄ + ⅙ I₆`,

где `Iₙ = Aⁿ (2π/n)^(3/2) R³`. Отрицательный заряд получается сменой знака ω и имеет ту же энергию. Это вариационная проба, не точное решение уравнения поля.

## План до запуска

Для `Q = 10, 100, 1000` минимизировать энергию по `0.1 ≤ A ≤ 2` и `0.5 ≤ R ≤ 20` на равномерной сетке 201×201 с последующими четырьмя локальными уточнениями по 41×41 точке. Вывести E/Q, ω, параметры профиля и положение относительно краёв области. Оценка чувствительности: выполнить тот же поиск для 101×101 с четырьмя локальными уточнениями. Нормировка и параметры выбраны как демонстрационные, без подгонки под физические массы.

Критерий предварительной связности: найденный профиль внутри области поиска и `E/Q < m = 1`; это доказывает существование пробной конфигурации ниже порога Q свободных квантов в данной классической модели, но не доказывает динамическую устойчивость, устойчивость к делению, квантование заряда или соответствие физическим частицам. Если критерий не выполнен, фиксировать отрицательный или неопределённый результат. Силы между сгустками, их знак и закон расстояния здесь не вычисляются.

Проверки расчёта: потенциал неотрицателен при всех f, и численное оптимальное значение не должно ухудшаться после локальных уточнений. Результаты сохраняются отдельно от протокола.

# Протокол: число порций до 9000

Записан до расчёта. Область: `scope = model`. Закон и порог `8` прежние. Карточку куба `n = 8` при `P = 1` не переписывать.

Вопрос: при том же старте элемент начинается и на большем числе порций, вплоть до `9000`.

## Сетка

`P = 1`. Радиус `1`, скорости ноль, фигура стенда. Числа:

`n = 64, 128, 256, 512, 1024, 2048, 4096, 8192, 9000`.

Срок до `t = 200`, либо пока две порции не дойдут до `2π`, либо пока внутри порога не останется меньше двух порций. Потолок шага `0,02`. Сужения `0,2 √(d/a)` и `0,02 d/v` остаются.

Потолок шагов, потому что на большом `n` один шаг дороже:

| n | шагов не больше |
|---|---|
| до 512 | 20000 |
| 1024 | 4000 |
| 2048 | 1000 |
| 4096 | 250 |
| 8192 | 50 |
| 9000 | 40 |

Если шаги кончились, а две порции внутри порога ещё не обернулись, ячейка не принята. Это обрыв срока, не выход за `8`.

Принятую ячейку с `n ≤ 256` повторить с потолком шага `0,002`.

## Приёмка

Не меньше двух порций с углом `2π`, у каждой отношение радиуса не больше `8`, ближайшая пара дальше `10⁻⁹`. Элемент на этой сетке начинается, если принята хотя бы одна ячейка.

## Что не утверждается

Это не химический элемент и не смена H0, H1, H2.

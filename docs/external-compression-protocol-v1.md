# Протокол E-COMP v1: проверка внешнего сжатия локального образования

Дата: 27.10.2026. Статус: **проект для согласования, до вычислительного опыта**. Область результата: `scope = model`. Заказчик согласился на подготовку конкретного протокола; запуск новой симуляции этим документом не объявляется выполненным. Старые результаты не переписываются.

## 1. Один вопрос

Может ли локальная система, составляющие которой взаимно отталкиваются по закону 1/r², сохранять ограниченный размер за счёт воздействий подвижного окружения, без отдельно заданной удерживающей силы?

Это проверка минимальной версии механизма, а не готовая модель элементарной частицы. Во второй серии «Гравитации» [05:11–06:45](https://www.youtube.com/watch?v=AA-ECUpj3xk&t=311s) описано внешнее сжатие, а в [17:15–21:21](https://www.youtube.com/watch?v=AA-ECUpj3xk&t=1035s) существенна реакция окружающей материи. Сопоставление терминов: [gravity-terminology-review-2026-10-27.md](gravity-terminology-review-2026-10-27.md).

## 2. Принятые термины и дополнительные предположения

**Из постановки заказчика:** пространство — бесконечный неограниченный объём; базовое гравитационное поле находится в нём; отдельные взаимодействия дальнодействующие; окружение может изменяться в ответ на локальное образование.

**Дополнительные предположения именно этой минимальной проверки:**

1. Локальное образование и внешняя материя представлены конечным набором эффективных материальных узлов в трёх измерениях. Узлы — вычислительное приближение, а не утверждение, что первичные составляющие поля являются материальными шариками.
2. На этом этапе собственное взаимодействие всех узлов — центральное взаимное отталкивание с положительными интенсивностями. Притяжение не добавляется отдельным членом.
3. Воздействие складывается векторно; восприимчивость всех узлов одинакова и нормирована к 1. Положительный модуль силы и направленная составляющая — разные величины.
4. Вводятся инерция и мгновенное квазистатическое парное взаимодействие. Волновой ритм, конечная скорость передачи, внутренние полевые степени свободы и синхронизация пока не представлены. Поэтому отрицательный результат этой версии не отвергает все возможные динамические модели поля.
5. Количественный показатель источника N_i и инерционная масса μ_i в нормированных единицах принимаются равными. Это упрощение; их связь на более глубоком уровне не выводится.

Число узлов, начальная геометрия, вращение и распределение окружения — заданные условия опыта, а не числа, выведенные из устройства природы. Цель v1 — проверить знак и наличие удержания; сравнение масс и абсолютных констант с природой не выполняется.

## 3. Уравнения

Для каждой пары i ≠ j:

`r_ij = x_i − x_j`, `d_ij = |r_ij|`,

`F_ij = κ N_i N_j r_ij/d_ij³`, `κ > 0`,

`μ_i d²x_i/dt² = Σ[j≠i] F_ij`.

Все узлы, включая внешние, подчиняются одному уравнению. Автоматически F_ji = −F_ij. Модуль парной силы равен κN_iN_j/d_ij²; пространственного радиуса отключения нет. Энергия замкнутого конечного набора:

`E = Σ μ_i |v_i|²/2 + κ Σ[i<j] N_iN_j/d_ij`.

Обозначение κ — общий коэффициент выбранной нормировки, соответствующий объединению коэффициентов исходной формулы при одинаковой восприимчивости. Его численное значение не выводится из монографии. Единицы: длина ℓ = 1, μ₀ = N₀ = 1, κ = 1; время τ = √(μ₀ℓ³/(κN₀²)).

Внешняя сила на узел образования: `F_i_ext = Σ[j∈окружение] F_ij`. Диагностика сжатия:

`y_i = x_i − X_образования`, `C_ext = Σ[i∈образование] y_i · F_i_ext`.

Отрицательное C_ext означает сжимающий вклад в радиальный вириальный баланс; положительное — расширяющий. Одна величина C_ext ещё не доказывает устойчивости. Ненулевая сумма модулей внешних сил не подставляется вместо их векторной суммы и не называется давлением без отдельного закона переноса импульса.

## 4. Первая обязательная проверка P0: сферическое окружение

Равномерная сферическая оболочка из одинаково действующих источников, радиус A, полный показатель N_s. Для внутренней точки x потенциальная энергия отталкивающего взаимодействия:

`U_ext(x) = κ N_probe ∫[оболочка] dN/|x−y| = κ N_probe N_s/A`, если |x| < A.

Следовательно, `F_ext = −∇U_ext = 0` **в любой внутренней точке**, не только в центре. Каждая частная сила ненулевая, но они компенсируются. Для нескольких концентрических оболочек результат тот же.

Это геометрическое следствие точного обратного квадрата. Вывод и условие сферической равномерности сверены с [Feynman Lectures II, 5–7 и 5–8](https://www.feynmanlectures.caltech.edu/II_05.html#Ch5-S7). Ссылка используется для проверки математического интеграла, а не как подмена механизма автора электричеством.

**Следствие для постановки:** равномерное неподвижное сферическое окружение в выбранной парной модели само по себе не сжимает образование в полости. Если для удержания нужны перенос импульса волнами, иное восприятие воздействия, динамическая перестройка или нелинейность, это должно появиться в уравнениях отдельно. Сжатие нельзя получить переименованием ненулевой суммы модулей в силу.

P0 проверяется до динамики: A = N_s = N_probe = κ = 1; точки r/A = 0, 0,25, 0,5, 0,75. Численная квадратура оболочки по cos(θ) — Гаусс–Лежандр, 16, 32, 64, 128 узлов; азимут при осевой геометрии интегрируется аналитически. На 128 узлах требовать |F| < 10⁻⁸ в единицах κN_probeN_s/A². Внешние контрольные точки r/A = 1,25 и 2 должны давать модуль 1/r² с относительной ошибкой < 10⁻⁸. Ненулевое внешнее поле обязательно: иначе «ноль внутри» может означать ошибку всей реализации.

## 5. Динамическая проверка P1: подвижное окружение

Она проверяет, может ли реакция окружения изменить вывод статического контроля. Начальные условия фиксируются заранее:

- 8 одинаковых центральных узлов в вершинах куба на сфере радиуса R₀ = 0,5ℓ. Все N_i = μ_i = 1.
- Окружение: узлы той же природы на кубической сетке шага ℓ, в области 1,5ℓ ≤ r ≤ R_ext; независимые смещения координат равномерны в [−0,1ℓ; +0,1ℓ]. Зёрна PCG64: 1, 2, 3.
- Для всех R_ext сначала генерировать одну решётку индексов от −8 до 8 по каждой оси, в лексикографическом порядке; смещения генерировать до отбора по расстоянию. Затем отбирать узлы по их фактическим смещённым координатам. Это обеспечивает вложенность окружений при фиксированном зерне.
- R_ext/ℓ = 4, 6, 8. Для сравнения радиусов использовать один и тот же бесконечно продолжаемый порядок координат и случайных смещений: меньшая область является подмножеством большей.
- Внешние скорости сначала нулевые. Центральные скорости: v_i = Ω e_z × y_i; Ωτ = 0, 0,5, 1. Вращение — заданный начальный параметр, не автоматически выведенная устойчивая орбита.
- Все внешние узлы свободны; стенок, отражения, нейтрализующего фона, скрытого отрицательного источника, трения, термостата и готового удерживающего потенциала нет.

Основная сетка условий — 3 радиуса × 3 зерна × 3 скорости вращения, всего 27 прогонов. Пилот для работоспособности реализации: R_ext = 4ℓ, seed = 1, Ω = 0; он сохраняется отдельно и не используется для изменения критериев без версии v2.

Число источников конечно только из-за вычислительного приближения. Это не утверждение об отсутствии базового поля снаружи области: ни одна имеющаяся парная связь не обрезается по расстоянию. Применимость приближения к бесконечному окружению проверяется увеличением R_ext; если зависимости не сходятся, вывод о бесконечном окружении не делается. Предел суммирования v1 — вложенные сферы с одним фиксированным центром; его независимость от формы области не предполагается.

Интегратор — velocity Verlet, dt = 0,002τ, t_max = 10τ, запись каждые 0,02τ. Численная регуляризация силы не применяется. При d_min < 0,05ℓ прогон останавливается как недостаточно разрешённый; дальше требуется отдельная версия с меньшим шагом, а не незаявленная замена закона силы. Уход за первоначальный R_ext не выключает узел из расчёта.

Обязательные контроли: центральная система без окружения; то же окружение с закреплёнными координатами (только контроль); повтор с dt/2 для минимального и максимального R_ext, seed = 1, каждого Ω. В контроле закреплённых источников сохранение импульса объединённой системы не проверяется как закон замкнутой динамики.

## 6. Что измеряется и что считается результатом

Сохранять временные ряды RMS-радиуса центральной группы, максимального расстояния от её центра, C_ext, плотности и распределения окружения, минимального расстояния, энергии, полного импульса и момента импульса. Состав центральной группы остаётся первоначальным: нельзя незаметно заменить ушедшие узлы новыми и назвать это сохранением той же частицы.

Качество численного прогона: max |E(t)−E(0)|/E(0) < 10⁻³; max |P(t)−P(0)|/(M_totalℓ/τ) < 10⁻⁸. Разница RMS-радиуса при dt и dt/2 на одинаковых временах < 1%. Непрохождение — недостоверный численный результат, а не физический распад.

Кандидат удержания: все 8 узлов остаются в пределах 2R₀ от своего центра, а max(R_rms)/min(R_rms) на t = 5…10τ ≤ 1,1. Это заданный критерий поиска кандидата, не доказательство устойчивости на бесконечном времени. Сжатие C_ext проверяется отдельно; его наличие не засчитывается вместо сохранения размера.

Для внешней среды дополнительно отслеживать r₉₅ — радиус относительно её центра масс, содержащий 95% внешних узлов, и эффективную среднюю плотность 0,95M_ext/(4πr₉₅³/3). Изменение этой плотности > 10% помечает существенную эволюцию конечного окружения. Такой опыт нельзя описывать как удержание стационарным базовым полем; расширение всей конечной модели само по себе не является опровержением схемы бесконечного окружения.

Сходимость по размеру окружения: для R_ext = 6ℓ и 8ℓ усреднённые по трём зёрнам R_rms и C_ext на t = 5…10τ различаются не более чем на 5% от максимального модуля сравниваемых значений, с абсолютным нижним масштабом 10⁻⁶ в соответствующих единицах. Все три R_ext должны давать одинаковую качественную классификацию. Прохождение — ограниченная проверка этих областей, не доказательство единственного бесконечного предела.

## 7. Условная проверка P2: возмущение и ослабление внешнего воздействия

Выполняется только если P1 нашёл кандидата с приемлемой численной точностью и без существенного изменения плотности окружения.

1. Из состояния t = 5τ отдельно сделать уменьшение/увеличение центральных расстояний на 5%, сохраняя центр и полный центральный момент импульса (относительные скорости масштабировать обратно). После продолжения на 5τ требовать возврата среднего радиуса последних 2τ в пределы 5% от невозмущённого контроля на тех же временах и сохранения всех восьми узлов в группе.
2. Из того же состояния в отдельном опыте удалить половину внешних узлов по заранее фиксированному правилу: каждый второй узел в исходном порядке генерации. Сохранившимся узлам не менять N и μ. Масса центрального образования остаётся прежней. Удаление — внешнее изменение условий; энергию и импульс до и после него не сравнивать как для замкнутой системы.
3. Предсказание автора, проверяемое в этом опыте: при ослаблении внешнего воздействия размер возрастает. Требование: средний радиус последних 2τ больше невозмущённого контроля минимум на 5% и больше численного/межзернового разброса; если группа распалась, фиксировать распад, а не новое равновесие.

## 8. Решение после опыта

- P0 не проходит → исправляется реализация суммирования; динамическая интерпретация откладывается.
- P0 проходит, P1 не даёт удержания → минимальная модель парного отталкивания не воспроизводит искомое сжатие в проверенных условиях. Отрицательный результат сохраняется.
- Доминирует расширение конечной внешней среды или нет сходимости → недостаточна модель бесконечного окружения; нельзя объявлять ни найденную частицу, ни опровержение общей схемы.
- P1 и P2 проходят → получен кандидат механизма внешнего удержания для этих условий. Только после этого готовится отдельный протокол двух образований и возникающего приталкивания.

В любом случае для полноценной полевой модели остаются открытыми внутренняя структура первичного узла, ритм, перенос импульса полем и физический смысл ненулевой базовой интенсивности при нулевой результирующей силе. Добавление этих механизмов — отдельная версия с явными уравнениями, а не правка текущих результатов задним числом.

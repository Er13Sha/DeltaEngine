# Схема поля заказчика: всё от одного источника

Сводка на 27.10.2026. Тезис заказчика: базовое гравитационное поле — единственный источник; тяготение, электричество, магнетизм, ядерные силы и свет — его проявления. Здесь собрано, что из этого проверено в проекте, чем и с каким результатом. Подробности — в отчётах по ссылкам.

## Закон

Формула воздействия (видео Rek8C322Q5k): W = Q·N, Q = k_пр·c1/(4πr²), N = h·S·ρ. В коде — `delta_science/action.py`, точная арифметика.

## Что проверено

| Проявление поля | Как в схеме | Проверка | Итог |
|---|---|---|---|
| Тяготение, величина | c1 = 4πG, N = масса | совпадает с законом Ньютона ровно | ✔ |
| Тяготение, механизм: экранирование потока Вселенной | поток со всех сторон, большее тело заслоняет; поток сильнее местной силы | закон 1/r² (−2,0001), третий закон, формула видео (c1 = 4π·I) | ✔ в модели |
| — торможение и нагрев (C6) | носители с конечной скоростью | Земля остановилась бы за 177 суток или нагрелась в 10³¹ раз сильнее | ✘ |
| — мгновенное действие | носители несут импульс почти без энергии, скорость ≥ 2·10²¹ c | торможение и нагрев ничтожны | ✔ условно |
| Электричество | c1 = 1/ε₀, N = заряд | закон Кулона до 10⁻¹⁰ | ✔ |
| Одноимённые заряды в потоке | притяжение, если G·m² > k·q² | у протонов отталкивание в 1,24·10³⁶ раз сильнее | ✔ условие, ✘ для частиц |
| Магнетизм | эффект движения при конечной скорости передачи | F_маг/F_эл = v²/c² точно; несёт заряд, не масса (10⁴³) | ✔ |
| Ядерные силы | затухающая передача k_пр = e^(−r/r₀), r₀ ≲ 1 фм | энергии связи 20 ядер: ошибка 8 % против 52 % без затухания | ✔ с расширением |
| Свет — частица в поле | поле — среда для света, n = 1 + 2GM/(rc²) | отклонение 1,751″, задержка Кассини: 0,9 σ; «просто притяжение» — 43 000 σ | ✔ |
| Скорость света зависит от поля | поле в равной мере меняет часы и масштабы | Паунд — Снайдер, Galileo, GPS (+38,4 мкс/сут) | ✔ |
| Волны тяготения | возмущения той же среды со скоростью c | GW170817: свет и волны замедлены одинаково (10⁻⁶) | ✔ |
| Мгновенная статика при волнах со скоростью c | — | двойной пульсар: убыль периода как у излучения со скоростью c (0,9983) | открыто |
| Частица — колебание поля (E3-волна, без параметров) | поле с инерцией и двумя состояниями | одна частица 0,96 F; сила: в фазе притяжение, в противофазе отталкивание; радиус по частоте предсказан (4 %); α ≈ 3 против ядерной 0,355 | ✔ форма, ✘ числа |
| Сила одна, отличается частотой | F = ħc·(f₁f₂/F²)·e^(−2πf_п·r/c)/r² | тяготение — точно из частот масс; частота ядра по дейтрону 3,35·10²² Гц = частота пиона (0,8 %) | ✔ радиус; сила — перевод измерений |

✔ — согласуется с моделью и измерениями; ✘ — опровергнуто; «условно» — проходит при указанном условии; «открыто» — не проверено.

## Открытые вопросы схемы

1. Откуда частоты силы: 2,52·10⁴¹ Гц у заряда и 1,76·10⁴² Гц у ядра при общей частоте поля 2,95·10⁴² Гц ([track-e-frequency.md](track-e-frequency.md)). Затухание ядерной передачи объяснено частотой 3,35·10²² Гц.
2. Как мгновенная статическая часть уживается с волнами, которые идут со скоростью c и уносят энергию двойного пульсара ровно по расчёту.
3. Что такое носитель, который передаёт импульс почти без энергии, и не противоречит ли он причинности.
4. Слабые взаимодействия (распад нейтрона) — не рассматривались.

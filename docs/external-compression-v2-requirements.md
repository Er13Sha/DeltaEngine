# E-COMP-v2: постоянный вселенский комплекс и взаимное экранирование

27.10.2026. Статус: **уточнённые требования; численный закон передачи ещё не выбран**. Область `scope = model`. Это дополнение к постановке по прямым указаниям заказчика, а не изменение завершённых результатов v1.

## Прямые уточнения заказчика

1. Учитывать константу — комплекс воздействий всех объектов Вселенной со всех сторон на каждую частицу.
2. Каждая частица взаимодействует с этим комплексом и с каждой другой частицей.
3. Каждая частица изменяет передачу всех воздействий, проходящих через неё; во взаимодействии участвуют все, «никакой статики».
4. На уточняющий вопрос получен ответ: «тело ещё и ослабляет воздействие, проходящее через». Следовательно, одной перестройки распределения окружения недостаточно: учитывается также прохождение с ослаблением.

Эти положения — принятые требования модели. Коэффициенты и механизм ослабления из них пока не следуют.

## 1. Что означает константа

Вводим отдельное рабочее обозначение B₀ для ненулевого базового уровня вселенского комплекса. Оно не заменяет C₁ монографии: C₁ описывает интенсивность, исходящую от единичной меры источника, а B₀ относится к совокупности внешних воздействий.

Для однозначного расчёта требуется различать распределение воздействия по направлениям и его результирующий вектор. Удобное предлагаемое представление — I₀ = B₀/(4π), одинаковое для всех направлений в базовом состоянии, и локальные изменения I_i(Ω,t). Нулевая сумма векторов при изотропии не означает нулевых отдельных воздействий. Постоянство B₀ — постоянство базового уровня, а не закрепление координат источников, сохранение каждой отдельной силы или запрет местных изменений.

При замене далёкой части Вселенной граничным условием необходимо описать и её ответ на исходящие воздействия. Неизменная внешняя сила на каждую частицу этому требованию не равнозначна. Нельзя без поправки прибавить полный B₀ к уже посчитанным источникам: возникнет двойной учёт части комплекса. Численное значение B₀ и его связь с источниками ещё не выведены.

## 2. Передача через тело

Сохраняется геометрическая часть исходной формулы. Для отдельного источника j и получателя i можно записать

`W_(j→i)(t) = [C₁ N_j/(4πr_ij(t)²)] T_(j→i)[X(t), состояние поля](t)`.

Здесь T — доля воздействия, дошедшая после прохождения промежуточных тел. В пространстве без промежуточного вещества T = 1; при ослаблении 0 < T < 1 для конечной оптической толщины. Передачу в обратную сторону также рассчитывать; симметрия не предполагается без проверки состояния и движения тел.

Это общая запись требования, а не готовый закон T. Она не определяет автоматически, какая часть взаимодействия воспринимается, поглощается или перераспределяется. Коэффициент k_a = 1 относится к передаче самим пространством; ослабление телами описывается отдельно. Возможная экспоненциальная передача exp(−τ) была бы дополнительной гипотезой, пока не принятой.

**Следствие для закона расстояния:** в свободном пространстве сохраняется 1/r². При наличии промежуточных тел полное воздействие равно T/r² и может отличаться от чистого обратного квадрата. Это нужно согласовать с прежней универсальной формулировкой, а не скрывать в расчёте. Искусственного радиуса выключения взаимодействия не вводить.

## 3. Все участники меняются

На каждом шаге времени должны учитываться источники, получатели и все промежуточные тела. Перемещение одного тела меняет расстояния, направления и прохождение воздействия для остальных. Полученные импульсы меняют движение участников, после чего всё распределение пересчитывается.

Для отдельного акта передачи требуется баланс:

`E_вход = E_прошедшее + E_перенаправленное + ΔE_тела + ΔE_поля`,

`p_вход = p_прошедшее + p_перенаправленное + Δp_тела + Δp_поля`.

Если через тело прошло меньше воздействия, нельзя просто удалить эту разницу из расчёта. При поглощении меняется энергия тела; при рассеянии учитывается выходящее поле; переданный импульс влияет на движение. В каждом случае требуется учесть также реакцию источника. Однако «ослабление» само по себе ещё не определяет распределение между перечисленными каналами.

W в исходной формуле автора не отождествляется автоматически с энергией E или мощностью потока. Превращать долю (1−T)W в нагрев без определения соответствующего энергетического потока нельзя. Балансы E и p — требования к будущему выбранному механизму передачи, а не уже полученная из коэффициента T формула нагрева.

Эффективный точечный узел v1 не имеет конечного сечения для прохождения сквозь него. В v2 необходимо задать либо конечную геометрию воспринимающего объёма, либо эффективное сечение и восприимчивость, либо разрешённые внутренние полевые степени свободы. Это новая часть приближения, а не скрыто известное свойство прежнего узла.

## 4. Что сохраняется от v1 и что он не проверяет

Контроль прозрачной равномерной сферической оболочки остаётся проверкой правильности векторного суммирования при T = 1. Он не утверждает нулевой силы в произвольной системе с промежуточными ослабляющими телами.

В v1 реализовано только взаимное центральное отталкивание подвижных эффективных узлов. Часть кампании сохранена до потери исполнительных сессий: состояние файлов сверяется отдельно. Этот опыт не содержит ни заданного постоянного вселенского комплекса, ни закона прохождения через ослабляющее тело. Его расширяющееся конечное окружение нельзя считать расчётом заявленного стационарного базового уровня.

Закреплённые узлы допускаются только как отдельные математические/численные контроли; основной вариант v2 должен быть динамическим. Полный протокол v1 не объявляется выполненным, незавершённые прогоны не возобновляются под видом v2.

## 5. Следующий небольшой результат

До расчёта образования частицы определить и проверить **один акт передачи**: источник → ослабляющее тело → получатель, с обновлением движения всех трёх и балансом энергии/импульса поля. Затем распространить то же правило на всех участников и на базовый вселенский комплекс. Только после этого проверять сжатие и устойчивость.

Открытые численные составляющие: закон T, геометрия/эффективное сечение, восприимчивость, способ передачи и переноса импульса, постоянный базовый уровень B₀ с учётом обратной реакции. Эти величины нельзя получить из самого слова «экранирование». Новая численная кампания v2 до их задания не заявляется.

# Протокол: спектр частиц по числу порций заряда

Записан до расчёта. Область: `scope = model`. Старые записи E1, осциллона и формулы видео не переписываются.

Постановка заказчика: разные частицы получаются из количества зарядов (квантов, порций) внутри самой частицы. Операционально: порция — ячейка с `δ = ±1`, число порций — заряд `Q` уплотнения.

## Модель

Семейство C, уже допущенное в [track-e-e1.md](track-e-e1.md): решётка `L = 96`, `J = 40`, `K = 1`, `R = 8`, температура `8`. Правило Кавасаки, сумма `δ` сохраняется. Притяжения разноимённых в правиле нет. Это не формула видео и не осциллон.

## Сетка

Число порций `n`: `1, 2, 3, 4, 6, 8, 12, 16, 24, 32`. Знак `+1`. Зёрна `1, 2, 3`. Срок `600` свипов. Частица не меньше `1` ячейки: порог E1 `s_min = 4` здесь не действует, иначе единица `n = 1` заранее отброшена.

**Сжатый старт.** `n` ячеек `+1`, ближайших к центру. Остальное — фон `0`.

**Контроль врозь.** Только `n = 4, 8, 16, 32`. Те же `n` ячеек `+1` на квадратной сетке с шагом `12`. Ожидание: не собираются в одну частицу заряда `n`, потому что одноимённые в C отталкиваются.

## Приёмка одной строки

После срока смотрят уплотнения того же знака.

- Держится как одна частица заряда `n`, если ровно одно такое уплотнение, его `Q = n`, число ячеек в `[⌈n/2⌉, 2n]`, и центр ушёл не дальше `8`.
- Распалась на копии, если уплотнений больше одного и все их заряды по модулю меньше `n`.
- Испарилась, если уплотнений нет.
- Иначе — прочее, записать мультимножество зарядов.

Строка сетки принята, если все три зерна держат одну частицу заряда `n`.

## Вердикт после всей сетки

- Элементарная порция есть, если `n = 1` принят.
- Лестница частиц есть, если приняты хотя бы два разных `n`.
- Большее `n` — только пачка копий, если ни одно `n ≥ 2` не принято сжатым стартом, а контроль врозь не собрался в одну частицу.
- Контроль врозь не должен собрать одну частицу заряда `n`. Если собрал — записать отдельно, лестницу по сжатому старту это не отменяет.

Сопоставление с протоном, нейтроном и электроном не входит. H0, H1, H2 не меняются.

Сверка силы пройдена. `P = 1`, скорости ноль, семена из `models/law.py`. Сила — локальное `1/r²`, открытые лучи и конус между лучами. Отрезок `[0,25; 400]` разделён 32 раза. Порог `8` не сдвигался.

## Радиус баланса

Корень есть, если среднее `a · r / |r|` меняет знак внутри отрезка. Середина последнего отрезка — радиус старта. Остаток наружу после 32 делений не больше `4·10⁻⁵`.

|---|---|---|
| 8 | нет | — |

| 32 | да | 1,994 |
| 64 | да | 2,575 |
| 128 | да | 3,327 |
| 256 | да | 4,347 |
| 512 | да | 5,699 |
| 1024 | да | 7,485 |
| 2048 | да | 9,841 |
| 4096 | да | 12,97 |
| 8192 | да | 17,15 |

У `n = 8` знак на обоих краях один и тот же: наружу. На правом краю `R = 400` среднее наружу ещё `+4,3·10⁻¹²`. Оборот от этого `n` не считался.

## Обороты

Срок до `t = 200`, либо два оборота, либо внутри порога меньше двух порций. Принятая ячейка с `n ≤ 256` повторена с потолком шага `0,002`. Ближайшая пара на всей сетке не ближе `0,118`, порог `10⁻⁹` нигде не сработал.

На потолке `0,02` у `n = 32`, `64` и `128` две порции доходят до `2π`, пока их собственное отношение не больше `8`. Худшее отношение в той же группе уже больше `8`. Повтор с потолком `0,002` двух таких порций не оставляет, поэтому ячейка не принята. У `n = 256` угол проходит `2π`, но такая порция уже вне порога. С `512` до `1024` бюджет шагов кончается раньше оборота, и размер части порций выходит за `8`. С `2048` до `9000` двести шагов кончаются, пока отношение ещё не больше `8` и двух оборотов нет.

## Вердикт

Радиус баланса есть у `n = 16, 32, 64, 128, 256, 512, 1024, 2048, 4096, 8192, 9000`. У `n = 8` корня на отрезке нет. Принятых ячеек нет: `held` пуст, элемент на этой сетке не начинается.

Это не химический элемент и не смена H0, H1, H2.

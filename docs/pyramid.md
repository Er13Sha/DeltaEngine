# Пирамида дельт материи и функция-характеристика

Версия 0.1, 27.10.2026. Код: `delta_science/pyramid.py`, деревья `data/trees/{particles,atoms,bonds,substances}.json`, страница `docs/pyramid.html` (генератор `python -m delta_app.pyramid_view`), опубликована: https://claude.ai/artifact/KS2SBvji7RjgJGJsXheUvr

## Требование

Все понятия строятся по дереву логических дельт; построение идёт от элементарных частиц до химических связей и веществ, от начала до конца, без погрешностей; связи показаны пирамидальным деревом.

## Как организовано

Одно бинарное дерево не может выразить «атом состоит из 11 протонов, 12 нейтронов и 11 электронов»: вилка делит множество на «A / не A» (отношение «вид — род»), а состав — другое отношение. Поэтому пирамида — это **уровни**, где:

- **внутри уровня** — дерево вилок ядра (классификация, функция-характеристика каждого узла);
- **между уровнями** — функции развёртки «состоит из», которые строят объект следующего уровня из объектов предыдущего.

```
Материя (дерево материи проекта)          ← вершина: объект приходит сюда агрегатным состоянием
  ↓ дискретная материя состоит из частиц
Элементарные частицы (particles.json)     нуклон / электрон; протон / нейтрон
  ↓ ядро = Z протонов + N нейтронов
Атомное ядро                              заряд +Z, масса нуклонов
  ↓ атом = ядро + Z электронов (правило Клечковского)
Атом (atoms.json)                         класс элемента по строению атома
  ↓ связь = пара атомов
Химическая связь (bonds.json)             металлическая / ионная / ковалентная
  ↓ вещество = атомы и связи
Вещество (substances.json)                простое / сложное; металл / ионное / ковалентное
```

## Что выводится из чего

| Шаг | Как получено | Статус |
|---|---|---|
| Частицы: заряд, масса | CODATA 2018 | измеренные константы |
| Ядро: состав, заряд, масса нуклонов | Z из номера элемента; N по школьному правилу (округлённая масса − Z) | точная арифметика |
| Электронные слои | развёртка из Z по правилу Клечковского; 19 известных «провалов» — из PubChem | 99 из 118 выводятся из Z |
| Класс элемента | дерево `atoms.json`: вилки индуктора по признакам, выведенным **только из Z** | 118 из 118 совпадают с PubChem; leave-one-out 111 из 118 |
| Дефект массы, энергия связи ядра | Σ масс частиц − масса атома (для 20 моноизотопных элементов) | Na: 186,564 МэВ, совпадает со справочным значением |
| Тип связи | дерево `bonds.json` по паре атомов | ядро |
| Вещество | дерево `substances.json` | ядро |
| Агрегатное состояние | PubChem → узел дерева материи | данные |

**Про «без погрешностей».** Вычисления точные: все числа — дроби, ничего не округляется по ходу. Погрешность остаётся только во входных измерениях (константы CODATA, массы PubChem), и она не скрывается. Это та граница, которую формулирует спецификация (раздел 1.3): вывод безошибочен относительно объявленной базы, а не относительно природы вне её. Там, где база — соглашение (граница ионной связи 1,7, список полуметаллов), это помечено в ответах.

Вилки дерева `atoms.json` открыты индуктором, поэтому до приёмки человеком они — гипотезы, и ответы через них получают статус «с допущениями».

## Функция-характеристика материи

**Что есть в материалах.** Авторы называют «функции-характеристики материи» первичным блоком, из которого разворачивается вся материя «по пирамидке» сверху вниз без погрешности вычисления (видео XsPHjlb_FZg 07:22, 12:07; ufII145N7W8 12:26). Сам блок, формулы или расчёты в доступных материалах не предъявлены: на прямой вопрос автор ответил, что базу данных не сделали (At08288FuLQ 22:03–60:35), тема форума с этим названием почти пуста (t1734). Это записано в спецификации (раздел 2.2).

**Что сделано в проекте.** Понятию дан операциональный смысл в двух частях.

1. **Функция-характеристика узла** (спецификация, раздел 5): χ_b(x) = ∏ b_i·δ_i(x) + (1 − b_i)·(1 − δ_i(x)) — объект относится к понятию, когда на каждой вилке пути он идёт в нужную сторону. В ядре это `Tree.characteristic(node)`: конъюнкция предикатов пути, которая компилируется и вычисляется как обычный предикат. Пример для жидкости: `grouped and not continuous and not planetary and not preservesShape and preservesVolume`. Тест проверяет тождество разбиения Σ χ_лист(x) = 1: каждый объект попадает ровно в один лист. χ показывается у каждого узла пирамиды и в ответах «что это».
2. **Генератор (развёртка)** — то, что авторы обещали как «первичный блок». Единой функции, из которой выводилась бы вся материя, нет ни в материалах, ни в науке. Вместо неё работает цепочка генераторов по уровням, и каждый проверяем: Z → ядро → электронные слои → класс элемента → связь → вещество → состояние. Развёртка любого из 118 элементов и 82 веществ строится по запросу и не хранится (принцип S-3: держать «тропинку», остальное разворачивать заново).

Если у заказчика появятся материалы с содержанием «первичного блока», его можно проверить в этой же схеме: он должен порождать те же уровни и проходить те же тесты.

## Как пользоваться

- Диалог: `python -m delta_app.chat "Из чего состоит натрий?"`, `"Развёртка воды"`, `"Что такое протон?"` (с χ).
- Страница: `python -m delta_app.pyramid_view` → `docs/pyramid.html`; выбор объекта подсвечивает его путь на каждом уровне.
- Дерево атомов: `python scripts/build_atoms_tree.py` (воспроизводимо, проверяется тестом).

## Следующие шаги

- Уровень «ядро» сделать деревом вилок (стабильные и радиоактивные ядра, изотопы) по данным о нуклидах.
- Связать верх пирамиды с моделью трека E (поле → уплотнение → частица), чтобы вершина «Материя» разворачивалась в частицы опытом на модели, а не постулатом.
- Кристаллические решётки и форма молекул как уровень между связью и веществом.

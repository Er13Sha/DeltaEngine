Данные: `data/experiments/field/` (протокол, таблица прогонов `delta-experiment@0.1`, сводка, перебор), дерево `data/trees/field_model.json`. Повторить: `python -m adapters.field_lattice.experiments` и `python -m adapters.field_lattice.experiments --scan` (нужны `numpy`, `numba`: `pip install -e .[field]`).

Все выводы относятся к модели (`scope = model`): опыт показывает, что возможно в модели, и не меняет статус посылок H0 и H2 об эмпирической реальности (спецификация, приложение C).

## Вопрос

Посылки заказчика: пространство заполнено полем (H0.P1), уплотнённое поле — частица (H0.P2), одноимённые отталкиваются (K1). Можно ли построить целочисленную модель поля, в которой уплотнения устойчивы (частицы существуют) и одноимённые частицы отталкиваются, причём притяжение не задано правилом напрямую?

## Модель

Решётка L × L с периодическими границами, в каждой ячейке целое отклонение поля от фона δ. Правило сохраняет сумму δ. Уплотнение — связная область одного знака; частица — уплотнение, которое сохраняет положение и размер через T свипов; заряд Q = Σ δ. Энергии целые, случайность — только через зерно, каждый прогон записан с хэшами протокола, кода и начальной конфигурации.

| Семейство | Правило | Роль |
|---|---|---|
| A | осыпание: ячейка с \|δ\| > 3 отдаёт по единице соседям | отрицательный контроль |
| B | обмен значениями соседей (динамика Кавасаки), сцепление J соседей одного знака | отрицательный контроль K1 |
| C | B + отталкивание одноимённых K·⌊R/r⌋ на расстоянии r ≤ R; притягивающего члена для разноимённых нет | кандидат |

## Результаты E1

| Семейство | Частицы существуют | Одноимённые | Разноимённые | Итог |
|---|---|---|---|---|
| A | нет (правило разглаживает любое уплотнение) | — | — | отклонено |
| B | да | притягиваются: энергия взаимодействия при касании −40, слияние в 2 из 12 прогонов | не взаимодействуют | K1 нарушен |
| C | да | отталкиваются: энергия взаимодействия 524 → 378 → 226 → 124 → 56 → 3 → 0 с ростом зазора, слияний нет | не взаимодействуют | **допущено** |

Оба отрицательных контроля провалили проверку, как требует протокол: проверка чувствительна.

## Функция-характеристика модели

Перебор параметров (J ∈ {10, 20, 40}, K ∈ {0, 1, 2}, T ∈ {4, 8, 16}, по 2 зерна) и индукция дали дерево из 3 вилок без ошибок на 27 наборах:

```
K = 0                      → частицы есть, одноимённые сливаются (K1 нарушен)
K·R/J > 6/5                → частиц нет: отталкивание соседей рвёт уплотнение
T/J > 6/5                  → частиц нет: тепловое движение сильнее сцепления
иначе                      → устойчивые частицы, одноимённые отталкиваются
```

Это и есть функция-характеристика в операциональном смысле плана (раздел 9.2): отображение параметров модели в класс устойчивых образований. Пороги 6/5 — середины между точками сетки перебора; точные границы лежат между ними и уточняются более частой сеткой.

## Отклонения от плана и ограничения

- **Решётка 2D**, а не 3D: для шипа. Теорема Деррика относится к 3D; проверка в 3D — следующий шаг.
- **K1 измеряется точной энергией взаимодействия пары**, а не ускорением: динамика модели передемпфирована, капли почти неподвижны. Дополнительно — динамика при касании (слияние или нет).
- **Параметры выбраны по пилотным прогонам**: при J = 4 и G(1) = 6 сцепление слабее отталкивания (C без частиц), при T/J ≥ 1/4 капли испаряются. Это записано в протоколе.
- **Сцепление внутри частицы** — короткодействующее притяжение одноимённых ячеек. Оно нужно для устойчивости (без него устойчивых локализованных решений нет) и действует только при касании; дальнего притяжения в правиле нет.
- Не проверены: притяжение разноимённых через экранирование (C1, семейство D), закон расстояния (C3), квантование заряда (C2), отношение масс (C4), сходимость при измельчении решётки.

## Что это даёт пирамиде

Вершина пирамиды «Материя → частицы» теперь не только постулат: в модели C переход «поле → устойчивое уплотнение (частица)» реализуем, и известны условия, при которых он происходит. На странице пирамиды это уровень «Поле → частица (модель)» с этим деревом и пометкой `scope = model`. Сопоставление частиц модели с протоном, нейтроном и электроном не доказано.

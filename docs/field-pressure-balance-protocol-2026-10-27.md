# Протокол: размер сгустка и наружное поле без камеры

Записан до расчёта. Область: `scope = model`. Это не правка E-COMP v1, v2 и не повтор стенда галактики. Жёсткой сферы нет: радиус ничем не ограничен сверху.

Выбор заказчика 27.10.2026: частица — поле в объёме; снаружи поле окружающей материи, оно остаётся при нулевой сумме сил; если наружное поле ослабло, размер растёт. Камеру разрешено убрать.

## Вопрос

При сохраняющемся заряде Q и взаимном отталкивании `1/r²`, растёт ли радиус области повышенного потенциала, если ослабить однородное наружное давление, и нет ли в счёте стенки?

## Допущение этого счёта

Наружное поле входит только как однородное давление `P`. В единицах расчёта `P` и есть интенсивность этого поля. Связь `P` с роликами не выведена: это допущение, чтобы у давления был размер, а у силы — ноль в равновесии. Прямого притяжения нет. Обрыва силы нет.

Две семьи, обе до запуска:

1. **Оболочка.** Заряд на сфере радиуса `R`. Внутри сила точно нулевая по теореме оболочки, потенциал `kQ/R` не нулевой. Энергия `kQ²/(2R)`.
2. **Шар.** Заряд равномерно в объёме. Потенциал выше в центре. Энергия `(3/5) kQ²/R`. Внутри сила на смещённую пробу не нулевая; в центре нулевая из симметрии.

Объём, по которому давление делает работу, `V = 4πR³/3`. Равновесие — минимум `E + PV`.

`k = 1`, `Q = 1`, инерция радиуса `μ = 1`.

## Предсказание до счёта

Из `d/dR (E + PV) = 0`:

- оболочка: `R⁴ = kQ² / (8πP)`, наружу `kQ²/(2R²)`, внутрь `4πR²P`;
- шар: `R⁴ = (3/5) kQ² / (4πP)`.

Ослабление `P` в 16 раз увеличивает `R` в `16^{1/4} = 2` раза. При `P = 0` правая часть бесконечна: радиус растёт без потолка. Это не камера.

Сетка `P`: `1`, `1/2`, `1/4`, `1/16`. Отдельно `P = 0`.

## Как считать

Уравнение `μ R̈ = −dE/dR − 4πR² P − γ Ṙ`, `γ = 1`. Трение нужно, чтобы колебание затухло к моменту записи. При `Ṙ = 0` и нулевой силе оно само равно нулю и положение равновесия не сдвигает. Это не камера и не потолок радиуса. Старт для `P = 1`: `R(0) = 0,5 R_равн`, `Ṙ(0) = 0`. Интегратор без максимального радиуса. Равновесие принято, если к концу `|R − R_формула| / R_формула < 10⁻³` и `|Ṙ| < 10⁻³`.

Затем из установившегося `P = 1` скачком поставить `P = 1/16` и дождаться нового равновесия. Ожидание: радиус вырастет вдвое с той же точностью.

Контроль оболочки: на сетке углов внутри сферы сила по модулю `< 10⁻¹⁰`, потенциал совпадает с `kQ/R` с относительной ошибкой `< 10⁻⁸`. Снаружи на тех же узлах относительная ошибка закона `1/r²` `< 10⁻⁸`. Порог «если сила мала, обнулить» не используется.

`P = 0`: старт с равновесного радиуса при `P = 1`, интеграл до `t = 5`. Ожидание: конечный радиус больше стартового хотя бы вдвое. Остановка на большом радиусе — только конец записи, не стенка в уравнении.

## Что не утверждается

Это не частица, не эмпирическая гравитация и не вывод давления из роликов. Стенд галактики и E-COMP здесь не пересматриваются.

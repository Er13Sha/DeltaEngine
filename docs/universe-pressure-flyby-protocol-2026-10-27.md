# Протокол: пролёт порций без столкновения

Записан до расчёта. Область: `scope = model`. Закон прежний: одноимённые порции отталкиваются как `1/r²` без обрыва. Комплекс — константа `P` к центру масс. Порции не слипаются и не занимают одну точку: при сближении сила растёт, траектории расходятся и проходят мимо.

Старые прогоны, где шаг останавливали при `r < 10⁻⁴`, не переписываются. Здесь остановка по столкновению запрещена. Если расстояние всё же падает ниже `10⁻⁴`, это отказ шага, не столкновение в законе.

## Сетка

Две порции массы `1`. Старт: `(−10, b/2, 0)` и `(+10, −b/2, 0)`, скорости `(+1, 0, 0)` и `(−1, 0, 0)`. Прицельный параметр `b = 0, 0,2, 0,5, 1, 2`. Давление `P = 0` и `P = 1`.

Базовый шаг `0,002`. Пока пара ближе `1`, шаг дробят так, чтобы за шаг проходить не больше `0,02` текущего расстояния. Срок `t = 40` или пока разлёт по `x` снова больше `20`.

## Приёмка

Столкновения нет, если наименьшее расстояние за прогон больше `10⁻⁴`.

При `b = 0` порции разворачиваются: первая заканчивает с `x < 0` и `v_x < 0`. Это не пролёт, это лобовой отскок без занятия одной точки.

При `b > 0` пролёт: к концу первая порция имеет `x` больше, чем вторая (стороны меняются), и столкновения нет.

Сетка принята, если все десять прогонов без столкновения, все `b > 0` дают пролёт, оба лобовых `b = 0` дают отскок.

## Что не утверждается

Пролёт не есть химическая связь. H0, H1, H2 не меняются.

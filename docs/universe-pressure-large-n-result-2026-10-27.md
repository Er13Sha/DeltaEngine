# Результат: одна частица при большом числе порций

Дата: 27.10.2026. Область: `scope = model`. Протокол: [universe-pressure-large-n-protocol-2026-10-27.md](universe-pressure-large-n-protocol-2026-10-27.md). Числа: `data/experiments/field/universe_pressure_large_n_2026-10-27.json`. Скрипт: `scripts/universe_pressure_large_n.py`.

Предел восьми порций снят. Сверка силы пройдена. Сборка сферы для `n = 8` дала радиус `1,57` — в допуске `[0,5; 3]`. `P = 1`. Сила `1/r²` не обрезалась.

## Сетка `P = 1`

| n | Срок | Стартовый R | Ошибка R | Принята |
|---|---|---|---|---|
| 8 | 50 | 1,57 | 0,111 | нет |
| 16 | 50 | 2,41 | 0,180 | нет |
| 32 | 50 | 3,59 | 0,382 | нет |
| 64 | 50 | 5,26 | 0,561 | нет |
| 128 | 5 | 7,60 | 0,00080 | да |
| 256 | 5 | 10,92 | 0,00040 | да |
| 512 | 5 | 15,61 | 0,00018 | да |
| 1024 | 5 | 22,24 | 8,8·10⁻⁵ | да |
| 2048 | 1 | 31,61 | 1,0·10⁻⁷ | да |
| 4096 | 1 | 44,86 | 4,0·10⁻⁸ | да |
| 8192 | 0,4 | 50,00 | 0,0494 | да по допуску срока |
| 16000 | 0,4 | 50,00 | 0,173 | да по допуску срока |

На `n = 8…64` срок полный, допуск `5%` не взят: сфера Фибоначчи за `t = 50` плывёт. Плоский восьмиугольник на той же константе раньше держался; эта сборка — другая.

С `n = 128` до `4096` радиус растёт с числом порций, ошибка на коротком сроке мала.

У `n = 8192` и `16000` стартовый радиус ровно `50`: это край поиска баланса, не найденное равновесие. Принятость на `t = 0,4` этот край не закрывает.

## Контроль `P = 0`

`n = 8`: среднее `41,8`. `n = 64`: `74,3`. `n = 256` за `t = 5`: `14,5` при старте `10,9`. Без комплекса разлёт.

## Вердикт

Число порций больше восьми считать можно. На этой сетке устойчивая сфера по полному сроку не принята. На коротком сроке радиус растёт с `n` до `4096`. Край `16000` без нового поиска радиуса не измерен. Это не вещество. H0, H1, H2 не меняются.

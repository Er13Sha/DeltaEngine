# Протокол: n = 100 без порога размера

Записан до расчёта. Область: `scope = model`. Закон прежний. Карточку `n = 100` с порогом `8` не переписывать. Куб `n = 8` при `P = 1` не переписывать.

Вопрос: без порога размера две порции на `n = 100` при `P = 1` доходят до полного оборота. Отношение радиуса в этой карточке пишется, но прогон не останавливает и приёмку не решает.

## Сетка

`P = 1`. Радиус `1`, скорости ноль, фигура стенда. Одно число: `n = 100`.

Срок до `t = 200`, либо пока две порции не дойдут до `2π`, либо `20000` шагов. Потолок шага `0,02`. Сужения `0,2 √(d/a)` и `0,02 d/v` остаются. Остановки по отношению радиуса нет.

Если шаги кончились, а двух оборотов нет, ячейка не принята. Это обрыв срока.

Принятую ячейку повторить с потолком шага `0,002`.

## Приёмка

Не меньше двух порций с углом `2π`, ближайшая пара дальше `10⁻⁹`. Элемент на этой ячейке начинается, если она принята.

## Что не утверждается

Это не химический элемент и не смена H0, H1, H2. Камера и отдельное поле не входят. Снятие порога `8` не меняет карточки, где он уже записан.

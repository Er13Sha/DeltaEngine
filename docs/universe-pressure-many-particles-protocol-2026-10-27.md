# Протокол: много частиц под давлением комплекса

Записан до расчёта. Область: `scope = model`. Закон прежний: одноимённые порции отталкиваются как `1/r²`, комплекс — константа `P` на каждую порцию к общему центру масс. Связь двух частиц не переписывается: её нет. Вопрос этой карточки — соберётся ли вещество, если частиц больше двух.

Частица здесь — уже принятая пара порций (`n = 2`, при `P = 1` расстояние до центра `1/2`). Число таких частиц `M` растёт по сетке. Искать `M` вне сетки и менять допуск после прогона нельзя.

## Сетка

`P = 1`. `M = 3, 4, 8, 16, 32, 64, 128`. Старт: центры частиц на кубической решётке с шагом `4 R`, `R = 1/2`. У каждой частицы две порции вдоль оси `x` своего центра. Скорости ноль.

Контроль: `P = 0` только для `M = 8`, те же места. Ожидание — разлёт.

Шаг `dt = 0,002`. Срок: `M ≤ 16` — `t = 5`; `M ≤ 64` — `t = 1`; `M = 128` — `t = 0,4`. Сближение порций ближе `10⁻⁴` останавливает прогон.

## Приёмка

Частица цела, если обе её порции ближе `2 R` к своему центру.

- Слияние: все порции лежат в шаре радиуса `3 R` вокруг общего центра — это одна большая частица, не вещество.
- Разлёт: среднеквадратичный радиус центров частиц больше `20` начального.
- Сборка вещества: целых частиц не меньше `3`, это не слияние, не разлёт, и среднеквадратичный радиус центров отклоняется от старта не больше чем на `20%`.
- Иначе — прочее.

Вещество на сетке появилось, если хотя бы одно `M` при `P = 1` дало сборку, а контроль `P = 0` при `M = 8` сборки не дал.

## Что не утверждается

Сборка не есть конкретное химическое вещество. H0, H1, H2 не меняются.

# Результат: связь двух частиц под давлением комплекса

Дата: 27.10.2026. Область: `scope = model`. Протокол: [universe-pressure-bond-protocol-2026-10-27.md](universe-pressure-bond-protocol-2026-10-27.md). Числа: `data/experiments/field/universe_pressure_bond_2026-10-27.json`. Скрипт: `scripts/universe_pressure_bond.py`.

Сверка силы пройдена. Радиус двух порций при `P = 1` равен `1/2`. Сетка `n = 2, 4`, `P = 1, 1/4, 0`, `D = 2R, 4R, 8R`, одноимённые и разноимённые — 36 прогонов. Связей по допуску карточки нет.

## Одноимённые

При `P > 0` две частицы либо сливаются в один комок, либо сближаются без устойчивого зазора. На `D = 2R` у `n = 2` прогон останавливается тесным сближением. Без давления (`P = 0`) на `D = 4R` и `8R` — разлёт.

## Разноимённые

Притяжение противоположных знаков не даёт связи: либо столкновение, либо разлёт на сотни и тысячи радиусов, либо слияние без двух целых частиц. Ни одна строка не держит расстояние центров в `[1,5 R; 12 R]` с размахом не больше `20%`.

## Вердикт

Вещество из связи двух частиц на этой сетке не начинается. Константа `P` собирает одноимённые порции в одну частицу и не держит две частицы на фиксированном мосте. Разноимённые без нового правила тоже не образуют устойчивую пару.

Это не молекула и не смена H0, H1, H2.

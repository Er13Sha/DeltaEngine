# Трек E, E3-заряд: частица с сохраняющимся зарядом (Q-шар)

Дата: 30.10.2026. Код: `adapters/field_lattice/qball.py`. Протокол записан до расчёта: `data/experiments/field/qball_protocol.json` (sha256:6c790d66…). Данные: `qball_family.json` (этап A), `qball_lifetime.json` (этап B).

## Постулаты (уточнение P3 после E3-волна)

Комплексное поле φ = |φ|·e^(iθ): модуль имеет два равновесных состояния одинаковой энергии, фаза свободна, заряд Q = ∫2·Im(φ*·φ_t)d³x сохраняется (P5). Уравнение φ_tt = ∇²φ − φ(1−|φ|²)(1−3|φ|²), c = F = 1, свободных безразмерных параметров нет.

## Этап A: семейство Q-шаров

Вращающийся сгусток φ = f(r)·e^(iωt), стрельба по ω ∈ [0,30; 0,99]. Q(ω) растёт при уменьшении ω, E/Q меняется от 0,82 до 1,04.

Кандидат в элементарную частицу по протоколу — наибольшее ω с dQ/dω < 0 и E < Q: **ω = 0,81**, Q = 49,04, E = 48,78, E/Q = 0,995.

## Этап B: живучесть

3D, сферическая симметрия, t_max = 5000, возмущение амплитуды ×1,01, критерий: заряд в ядре r < 20 держится в пределах 1%.

| Q-шар | Макс. относительное изменение заряда | Вердикт |
|---|---|---|
| ω = 0,81 (кандидат) | 4·10⁻⁵ | устойчив |
| ω = 0,95 (отрицательный контроль, dQ/dω > 0) | 2,9·10⁻² | распадается |

Контроль добавлен после пилота. Протокольный контроль (осциллон) за t_max = 5000 не различает: осциллон живёт около 10⁴ единиц времени. Контроль с ω = 0,95 отсеивает неустойчивое — критерий работает.

Заряд стартового состояния 50,02 = 49,04 · 1,01² — согласуется с тем, что Q ∝ амплитуда².

## Что это значит

Q-шар с ω = 0,81 — долгоживущая частица с сохраняющимся зарядом, и её заряд задаётся самим полем, без параметров. Это уже не то, что у поля с двумя состояниями (E3-волна): там частица легче переносчика и не имеет заряда.

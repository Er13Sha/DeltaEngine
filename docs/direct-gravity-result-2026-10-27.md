# Результат: прямая гравитация двух масс

Дата: 27.10.2026. Область: `scope = model`. Протокол: [direct-gravity-protocol-2026-10-27.md](direct-gravity-protocol-2026-10-27.md). Числа: `data/experiments/field/direct_gravity_2026-10-27.json`. Скрипт: `scripts/direct_gravity.py`.

Отдельного поля, давления и камеры нет. Величина силы — формула тяготения из `delta_science/action.py`: `c1 = 4πG`, `F = G N₁ N₂ / r²`. Сверка с законом Ньютона для двух протонов на 1 м в этой формуле точная. Направление в счёте — притяжение.

`G = 1`, массы `1`, начальное расстояние `1`, круговая скорость `1/√2`, десять периодов, `dt = T/4000`.

## Что получилось

| Проверка | Результат |
|---|---|
| Орбита | Конечное расстояние `1`. Наибольшее относительное отклонение `1,23·10⁻⁶`, порог `10⁻⁴` взят |
| `G = 0`, те же скорости, время одного периода | Расстояние `6,3622651` совпало с `√(1 + 2 T²)`, ошибка `5·10⁻¹⁴`. Это больше 2 |
| Четыре массы вокруг центра | Каждый вклад `0,5`, векторная сумма `0` |

Пара остаётся на конечном расстоянии, пока связь — гравитация. Без неё то же начальное движение разводит массы. В центре квадрата сумма сил нулевая, каждый вклад при этом не нулевой.

## Вердикт

Для этой пары закона `F = G N₁ N₂ / r²` достаточно: стенка и отдельная полевая величина не понадобились. Это орбита двух масс, не частица и не внешнее сжатие. H0, H1 и H2 не меняются.

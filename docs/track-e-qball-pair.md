# Трек E, E3-заряд, этап C: силы между Q-шарами

Дата: 30.10.2026. Код: `adapters/field_lattice/qball.py` (`pair_run`). Протокол записан и закоммичен до расчёта: `data/experiments/field/qball_protocol.json` (раздел `C_pairs`, хэш проверен). Данные: `data/experiments/field/qball_pair.json`. Повторить: прогон по `C_pairs` (см. раздел «Как запускать»).

## Постановка

Два Q-шара с ω = 0,81 (кандидат из этапа A; Q = 49,04, E = 48,78, S = E/ω = 60,2) ставятся на ось z на расстоянии d и отпускаются из покоя. Три случая по протоколу:
- **same_in** — одинаковый заряд, фазы совпадают;
- **same_anti** — одинаковый заряд, фазы противоположны;
- **opposite** — заряды ω и −ω, при t = 0 фазы совпадают.

Расстояния 10, 12, 14, 16; контроль d = 32. 3D, осевая симметрия, h = 0,1, dt = 0,05, t_max = 150. Измерение как в этапе 2 E3-волна (v3): центр энергии в окне 6, ускорение из подгонки до смещения 1.

## Результаты (по протоколу, все 15 прогонов)

| d | same_in (сила) | same_anti (сила) | opposite (сила) |
|---|---|---|---|
| 10 | **притяжение**, слияние (−0,122) | отталкивание (+0,065) | слабое притяжение (−0,004) |
| 12 | **притяжение**, слияние (−0,025) | отталкивание (+0,016) | ≈ 0 |
| 14 | притяжение (−0,006) | отталкивание (+0,004) | ≈ 0 |
| 16 | притяжение (−0,0016) | отталкивание (+0,0012) | ≈ 0 |
| 32 (контроль) | ≈ 0 | ≈ 0 | ≈ 0 |

## Что это значит

1. **Знак задаёт относительная фаза.** Два одинаковых Q-шара в фазе притягиваются и сливаются, в противофазе — отталкиваются. Отдельного закона для притяжения и отталкивания нет, тот же результат, что на этапе E3-волна, но уже для частиц с сохраняющимся зарядом.
2. **Противоположные заряды почти не взаимодействуют.** Сила ≈ 0 при d ≥ 12. Возможная причина: взаимодействие пропорционально Re(φ₁*φ₂), а для ω и −ω это произведение колеблется на частоте 2ω и в среднем обращается в ноль. Этого не проверяли отдельно.
3. **Радиус силы совпадает с предсказанием по частоте.** Предсказано до расчёта: κ = √(1 − ω²) = 0,586. Для противофазы подгонка даёт κ = 0,5745 (отклонение 2 %). Для фазы κ = 0,634 (отклонение 8 %), но там слияние при d = 10 и 12 ломает подгонку.
4. **Безразмерная сила взаимодействия** α_модель = g/S: противофаза ≈ 5,0–5,7, фаза ≈ 8,6–14,8 (по разным подгонкам). Подгонка по 4 точкам, поэтому разброс велик.

## Сравнение с природой (по протоколу, после расчёта)

| | Модель | Природа | Итог |
|---|---|---|---|
| Сила (основное) | α ≈ 5 | ядерная α_N = 0,355 | в ~15 раз больше — не совпадает |
| Сила (для полноты) | α ≈ 5 | электричество 1/137 | в ~700 раз больше — не совпадает |
| Знак одноимённых | в фазе — притяжение, в противофазе — отталкивание | электричество: одноимённые отталкиваются | зависит от фазы; не совпадает безусловно |
| Знак разноимённых | почти нет взаимодействия | электричество: притягиваются | не совпадает |
| Радиус силы | по частоте, предсказан (2 %) | ядро: по частоте пиона | совпадает по схеме, числа не проверены |

## Ограничения

- Подгонка по 4 расстояниям; для фазы часть точек в режиме слияния.
- Одна частота (ω = 0,81), одна энергия; сравнение с другими частотами не делалось.
- Разница с природой в знаке для разноимённых — главный вывод: модель не воспроизводит, что разноимённые притягиваются сильно.

## Как запускать

```
python -m adapters.field_lattice.experiments --qball-pair
```
Функция `pair_experiment` в `adapters/field_lattice/qball.py` берёт параметры из `QB_PROTOCOL['C_pairs']`, пишет `qball_pair.json`. Повторный запуск даёт те же силы до четвёртого знака. Блок `post_hoc` (подгонки после расчёта) добавляется отдельно и в CLI не входит.

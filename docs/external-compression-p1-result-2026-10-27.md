## P0, уже пройден

Равномерная оболочка, квадратура 128 узлов: внутри `|F| ≤ 4,5·10⁻¹⁴` при допуске `10⁻⁸`; снаружи относительная ошибка `1/r²` ≤ `6,5·10⁻¹⁴` при допуске `10⁻⁸`. Это проверка интеграла, не удержание группы.

## Какие прогоны есть и чего нет

Записано 34 файла: 27 закреплённых (`frozen`), 3 изолированных, 3 подвижных с `dt = 0,001τ` при `R_ext = 4ℓ`, seed = 1, и пилот `mobile`, `R_ext = 4ℓ`, seed = 1, `Ω = 0`, `dt = 0,002τ`.

Основная сетка P1 — 27 подвижных прогонов `dt = 0,002τ` на `R_ext ∈ {4,6,8}ℓ`, трёх зёрнах и трёх `Ω` — **отсутствует**, кроме пилота. Пилот по протоколу не меняет критерии без версии v2; ниже он только как единственная подвижная точка с основным шагом.

Повтор `dt/2` для максимального `R_ext = 8ℓ` **отсутствует** (три файла). Сравнение шага по времени установлено только для `R_ext = 4ℓ`, seed = 1, `Ω = 0`.

Сходимость подвижного семейства по `R_ext = 6ℓ` и `8ℓ` — **UNKNOWN**: прогонов нет.

## Численное качество

У 32 полных прогонов `max |E(t)−E(0)|/E(0)` от `1,0·10⁻⁸` до `5,4·10⁻⁶`, все ниже `10⁻³`.

Импульс замкнутой системы: изолированные и подвижные — нормированный уход `≲ 10⁻¹⁴`, ниже `10⁻⁸`. У закреплённых координат импульс объединённой системы не закон; уход `0,008…0,15` и в критерий качества не входит.

Сравнение `dt` и `dt/2` на совпадающих временах, пилот против `mobile-R4-seed1-omega0-dt0.001`: 501 точка до `t = 10τ`, наибольшая относительная разница RMS-радиуса `1,53·10⁻⁶` < 1%. Для остальных `Ω` и для `R_ext = 8ℓ` пара шагов **UNKNOWN**.

Два прогона остановлены как `unresolved_close_pair` и в успех не переименовываются:

| Прогон | `t_кон` | `max r` уже к остановке | окно 5…10τ | последняя записанная `d_min` |
|---|---:|---:|---|---:|
| `frozen-R6-seed3-omega0-dt0.002` | 1,50τ | 6,48ℓ | нет | 0,179ℓ |
| `frozen-R8-seed1-omega1-dt0.002` | 1,58τ | 8,52ℓ | нет | 0,200ℓ |

Порог остановки `d_min < 0,05ℓ`. Точное расстояние на шаге остановки в `trace` не попало: запись идёт каждые `0,02τ`, а обрыв — между образцами. Это **UNKNOWN**, не «пара осталась разрешённой». К моменту обрыва оба прогона уже вне `2R₀`.

## Удержание

Ни один из 34 прогонов не кандидат. У 32 полных `max r` на траектории от 25,9ℓ до 292ℓ при пороге 1ℓ; отношение RMS на окне 2,01…2,60 при пороге 1,1.

Начальное `C_ext` у окружённых конфигураций слабо отрицательное (сжимающий вклад порядка −0,15…−0,20). Это не удержание: к `t = 5…10τ` у закреплённой решётки `C_ext` уже большое положительное, у подвижной среды знак зависит от `Ω` и по модулю ≪ расширения группы.

## Семьи

**Изолированная восьмёрка** (нет внешних узлов). Все три `Ω` полные, численно достоверны. RMS на окне ≈ 22,5ℓ, конечный RMS ≈ 30,3ℓ. `C_ext = 0`. Ожидаемый разлёт взаимным отталкиванием; внешнего сжатия нет.

**Закреплённые координаты окружения** — контроль, не реакционное окружение автора. 25 полных, 2 обрыва. Плотность внешних узлов не меняется (`r₉₅` заморожен). Группа разлетается сильнее изолированной: оконный RMS ≈ 71…80ℓ при `R_ext = 4ℓ`, ≈ 112…123ℓ при 6ℓ, ≈ 148…161ℓ при 8ℓ. Больше закреплённых источников — больше позднего выталкивания, не больше удержания. Качественный класс на всех трёх `R_ext`: нет удержания.

**Подвижное окружение** — собственно P1. Четыре полных прогона только при `R_ext = 4ℓ`, seed = 1. Численно достоверны. Оконный RMS ≈ 18,9ℓ (`Ω = 0`), 20,2ℓ и 22,2ℓ (`Ω = 0,5` и 1). Это того же порядка, что изоляция, и меньше закреплённой решётки. Критерий размера не выполнен. Плотность конечной среды падает с 0,956 до ≈ 6,43·10⁻⁵: относительный уход ≈ 0,99993 > 10%. `r₉₅` с 3,81ℓ до 93,8ℓ. Это нельзя описывать как удержание стационарным базовым гравитационным полем. Расширение конечной модели само по себе не опровергает схему бесконечного окружения.

## Вердикт по разделу 8

P0 пройден.

**P1 не даёт удержания.** В проверенных условиях минимальная модель парного отталкивания `1/r²` без отдельной удерживающей силы не сохраняет ограниченный размер центральной восьмёрки. Это относится к изоляции, к закреплённой решётке и к тем подвижным прогонам, которые записаны. Отрицательный результат сохраняется.

Одновременно у подвижного окружения **доминирует расширение конечной внешней среды**, а сходимость подвижного P1 по `R_ext = 6ℓ` и `8ℓ` не установлена. Недостаточна модель бесконечного окружения: нельзя объявлять найденную частицу и нельзя объявлять опровержение общей схемы бесконечных внешних воздействий. Изоляция и закреплённый контроль уже показывают разлёт без этой схемы; пробел сетки не переименовывает этот разлёт в удержание.

P2 не выполняется: нет кандидата с приемлемой численной точностью и без существенного изменения плотности окружения.

## Что не утверждается

- Не частица, не элементарный заряд, не масса, не частота.
- Не гравитация природы и не эмпирическая констатация.
- Статус H0, H1, H2 и положений Катющика не меняется.
- Экранирование поглощением потока — другой механизм, чем внешнее сжатие автора; этот опыт его не проверяет.
- Закреплённая оболочка — не реакционное окружение второй серии «Гравитации».
- Слабо отрицательное начальное `C_ext` — не доказательство устойчивости.
- Отсутствие 26 подвижных точек основной сетки не заполняется экстраполяцией.

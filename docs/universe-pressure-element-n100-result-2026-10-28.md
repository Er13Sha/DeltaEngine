# Результат: одна ячейка n = 100

Дата: 28.10.2026. Область: `scope = model`. Протокол: [universe-pressure-element-n100-protocol-2026-10-28.md](universe-pressure-element-n100-protocol-2026-10-28.md). Числа: `data/experiments/field/universe_pressure_element_n100_2026-10-28.json`. Скрипт: `scripts/universe_pressure_element_n100.py`.

Сверка силы пройдена. `P = 1`, старт с радиуса `1`, скорости ноль, фигура стенда. Порог `8` не менялся. Потолок шага `0,02`.

Угол до `2π` не дошёл. Внутри порога к остановке не осталось ни одной порции. Ближайшая пара `0,309`. Шаги не кончились: потолок был `20000`. Повтор с потолком шага `0,002` не делался, ячейка не принята.

## Вердикт

На `n = 100` элемент не начинается. Порог не сдвигался. Числа выше `100` в эту карточку не входят.

Это не химический элемент и не смена H0, H1, H2.

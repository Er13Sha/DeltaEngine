# Результат: пролёт порций без столкновения

Дата: 27.10.2026. Область: `scope = model`. Протокол: [universe-pressure-flyby-protocol-2026-10-27.md](universe-pressure-flyby-protocol-2026-10-27.md). Числа: `data/experiments/field/universe_pressure_flyby_2026-10-27.json`. Скрипт: `scripts/universe_pressure_flyby.py`.

Сверка силы пройдена. Закон не обрезан: при сближении шаг дробят. Остановки «столкновение в точке» нет.

## Что вышло

Во всех десяти прогонах наименьшее расстояние больше `10⁻⁴`. Порции не занимают одну точку.

Лобовые `b = 0` при `P = 0` и `P = 1` — отскок: первая порция уходит с `x < 0` и `v_x < 0`. Ближайшее сближение `0,95` без давления и `0,048` при `P = 1`.

Прицельный параметр `b ≥ 1`: стороны меняются, это пролёт. При `b = 0,2` — обратное рассеяние, не пролёт: сила `1/r²` разворачивает почти как лобовой удар. При `b = 0,5` без давления порции разминулись по `x`, но к `t = 40` ещё у центра; при `P = 1` на том же `b` стороны не поменялись.

Сетка целиком не принята: условие «всякое `b > 0` есть пролёт» для этого закона слишком сильное. Столкновений нет.

## Вердикт

Порции отталкиваются и не слипаются в точку. Мимо проходят, когда прицельный параметр не слишком мал. Малое `b` даёт разворот, не контакт. Константа `P` сближает сильнее и не создаёт столкновения.

Это не связь вещества и не смена H0, H1, H2.

# Протокол: одна частица при большом числе порций

Записан до расчёта. Область: `scope = model`. Закон прежний: одноимённые порции отталкиваются как `1/r²`, комплекс удалённых тел — константа давления `P` на каждую порцию к центру масс. Точечных дальних масс нет. Стенки нет. Сила не обрывается. Карточки `n ≤ 8` не переписываются.

Предел восьми порций снят. Сетка до `16000`.

## Сетка

`P = 1`. Число порций `n = 8, 16, 32, 64, 128, 256, 512, 1024, 2048, 4096, 8192, 16000`.

Старт — решётка Фибоначчи на сфере, радиус из баланса радиального отталкивания и `P`. Скорости ноль. Для `n = 8` при `P = 1` этот радиус должен быть того же порядка, что у плоского шести- и восьмиугольника из прежней карточки (не меньше `0,5` и не больше `3`), иначе сборку сферы не считать.

Контроль без комплекса: `P = 0` только для `n = 8, 64, 256`. Радиус старта берут от `P = 1`. Ожидание — разлёт.

Шаг `dt = 0,002`. Срок по `n`, зафиксирован до запуска:

- `n ≤ 64`: `t = 50` (`25000` шагов);
- `65 ≤ n ≤ 1024`: `t = 5`;
- `1025 ≤ n ≤ 4096`: `t = 1`;
- `n ≥ 4097`: `t = 0,4`.

Сближение ближе `10⁻⁴` останавливает прогон.

## Приёмка

`R` — среднее расстояние порций до центра масс. При `P = 1` частица принята, если нет сближения и `R` отклоняется от старта не больше чем на `5%`. При `P = 0` принятой не считается, если среднее `R` больше чем вдвое относительно старта.

Лестница: среди принятых при `P = 1` наибольший стартовый радиус больше наименьшего хотя бы на `5%`.

## Что не утверждается

Большое `n` не есть вещество и не есть молекула. H0, H1, H2 не меняются.

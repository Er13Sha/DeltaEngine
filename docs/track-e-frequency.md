# Трек E: сила одна, силы отличаются частотой колебания поля

Дата: 27.10.2026. Код: `adapters/field_lattice/frequency.py`, данные: `data/experiments/field/frequency.json`. Повторить: `python -m adapters.field_lattice.experiments --frequency`.

## Тезис заказчика

«Сила одна, она отличается частотой колебания поля. Нужно вычислить это». Проверка опирается только на схему проекта и измерения; сторонние теории не привлекаются.

## Закон одной силы

```
F = ħc · (f₁·f₂ / F²) · e^(−2π·f_п·r/c) / r²
```

- f₁, f₂ — частоты колебания двух тел (для массы f = m·c²/h);
- F = 2,952·10⁴² Гц — одна общая частота поля;
- f_п — частота колебания, которое передаёт воздействие: оно затухает на длине r₀ = c/(2π·f_п). Это коэффициент пространственной передачи k_пр из формулы видео.

Частоты задают обе величины, которыми различаются силы: **силу** (через f₁·f₂/F²) и **радиус действия** (через f_п).

## 1. Сила различается частотой

Для тяготения закон совпадает с законом Ньютона точно, без подгонки: G·m₁·m₂ = ħc·f₁·f₂/F². Частота колебания массы протона — 2,269·10²³ Гц. Каждой силе соответствует своя частота f = √α·F:

| Сила | Безразмерная сила α (два протона) | Частота колебания |
|---|---|---|
| Тяготение | 5,906·10⁻³⁹ | 2,27·10²³ Гц (масса протона) |
| Электричество | 7,297·10⁻³ (1/137) | 2,52·10⁴¹ Гц |
| Ядерная | 0,355 (по дейтрону, ниже) | 1,76·10⁴² Гц |
| Общая частота поля F | 1 | 2,95·10⁴² Гц |

Электричество сильнее тяготения в (2,52·10⁴¹ / 2,27·10²³)² = 1,24·10³⁶ раз — это то же отношение, что получено раньше другим путём.

**Честная граница.** Эта часть — перевод трёх измеренных сил на язык частот: три числа на входе, три на выходе. Предсказанием она станет, когда частоты 2,52·10⁴¹ Гц (заряд) и 1,76·10⁴² Гц (ядро) удастся вывести из устройства поля, а не взять из измерений.

## 2. Радиус действия задаётся частотой: расчёт по дейтрону

Дейтрон — протон и нейтрон, связанные ядерной силой. Решается уравнение Шрёдингера с потенциалом −g·e^(−r/r₀)/r (метод Рунге — Кутты, шаг 0,002 фм). Для каждого радиуса r₀ сила g подбирается по одной величине — энергии связи 2,2246 МэВ. Три другие величины становятся предсказаниями и сравниваются с измерениями.

| r₀, фм | Частота f_п, Гц | Радиус дейтрона, фм | Длина рассеяния n–p, фм | Эффективный радиус, фм | Ошибка |
|---|---|---|---|---|---|
| 0,5 | 9,5·10²² | 1,70 | 4,80 | 0,87 | 31 % |
| 1,0 | 4,8·10²² | 1,86 | 5,18 | 1,44 | 11 % |
| **1,425** | **3,35·10²²** | **1,969** | **5,419** | **1,756** | **0,2 %** |
| 2,0 | 2,4·10²² | 2,10 | 5,61 | 1,98 | 9 % |
| 3,0 | 1,6·10²² | 2,28 | 5,47 | 1,82 | 9 % |
| Измерено | | 1,975 | 5,4194 | 1,753 | |

**Частота ядерного колебания по одному только дейтрону: 3,348·10²² Гц.** Частота пиона, измеренная отдельно (масса 139,570 МэВ, f = mc²/h): 3,375·10²² Гц. **Совпадение 0,8 %.**

На языке схемы: ядерное воздействие передаётся колебанием поля с частотой 3,35·10²² Гц, поэтому затухает на 1,4 фм; квант этого колебания (h·f = 139,6 МэВ) наблюдается как отдельная частица — пион. У тяготения и электричества передающее колебание не затухает (f_п = 0), поэтому они действуют на любом расстоянии.

## Итог

| Что | Результат |
|---|---|
| Одна формула для всех сил | F = ħc·(f₁f₂/F²)·e^(−2πf_п r/c)/r² — да |
| Тяготение из частот масс | точно, без подгонки |
| Радиус ядерных сил из частоты | предсказан по дейтрону и совпал с частотой пиона на 0,8 % |
| Сила заряда и ядра из частот | пока перевод измерений; вывод частот 2,52·10⁴¹ и 1,76·10⁴² Гц — следующая задача |

Ограничения: только центральная сила в S-состоянии (без спин-орбитальной и тензорной части); слабые взаимодействия не рассматривались.

# Результат: сжатие вселенной как константа модели

Дата: 27.10.2026. Область: `scope = model`. Протокол: [universe-constant-protocol-2026-10-27.md](universe-constant-protocol-2026-10-27.md). Числа: `data/experiments/field/universe_constant_2026-10-27.json`. Скрипт: `scripts/universe_constant.py`.

Сверка величины силы пройдена. Для двух порций радиус при `Ω² = 1` равен `(1/4)^{1/3} = 0,6299605249474366`.

Внутри порции отталкиваются по `1/r²`. Сжатие вселенной — константа `Ω²`, ускорение `−Ω² (x − x_cm)`. Точечных масс вселенной нет.

## Сетка

Срок `t = 50`. Ошибка радиуса при `Ω² > 0` везде ноль в пределах `10⁻¹⁵`. Без константы порции разлетаются.

| n | R при Ω² = 1 | Ω² = 1/4 | Ω² = 1/16 | Ω² = 0, среднее | Принята при Ω² = 1 |
|---|---|---|---|---|---|
| 2 | 0,630 | 1,000 | 1,587 | 21,2 | да |
| 3 | 0,833 | 1,322 | 2,098 | 28,0 | да |
| 4 | 0,985 | 1,564 | 2,483 | 33,1 | да |
| 6 | 1,223 | 1,941 | 3,081 | 41,1 | да |
| 8 | 1,410 | 2,239 | 3,554 | 47,4 | да |

Отношение `R(1/16) / R(1)` для всех пяти `n` равно `2,520`, как `(16)^{1/3}`. Порог был `2`.

## Вердикт

Константа `Ω²` удерживает структуру: при `Ω² = 1, 1/4, 1/16` все `n = 2, 3, 4, 6, 8` приняты, без неё разлёт больше чем вдвое. Она задаёт размер: ослабление в 16 раз увеличивает радиус в `2,520` раза. Разные `n` дают разные радиусы при том же `Ω²`, лестница есть.

Это не вывод константы из суммы тел вселенной. Та сумма для `1/r²` внутри сферы около нуля. Член добавлен отдельно, потому что без него отталкивающиеся порции не держатся. Не протон и не электрон. H0, H1, H2 не меняются.

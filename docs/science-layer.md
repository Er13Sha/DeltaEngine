# Слой учебной физики и химии: строение, связи, причины

Версия 0.1, 27.10.2026. Код: `delta_science/`. Данные: `data/sources/pubchem/`, `data/trees/bonds.json`, `data/knowledge/`.

Задача: у слова «натрий» должны быть не только название и класс, а числовое строение вещества — атом, его электроны, связи атомов — и причинные объяснения свойств. Слой заложен тремя уровнями; каждый вывод проверяет ядро.

## 1. Строение (числа)

**Атом** (`delta_science/atoms.py`). Электронная конфигурация не хранится, а разворачивается из заряда ядра Z по правилу Клечковского (подуровни по возрастанию n + l, при равенстве — по n; ёмкость 2·(2l + 1)) и сверяется с конфигурацией PubChem.

- Совпадение у 99 элементов из 118. Расхождения ровно у 19 — это известные по учебникам «провалы» электрона (Cr, Cu, Nb, Mo, Ru, Rh, Pd, Ag, La, Ce, Gd, Pt, Au, Ac, Th, Pa, U, Np, Cm); для них фактическое строение берётся из PubChem, а расхождение показывается в ответе.
- Выводятся: протоны и электроны (= Z), нейтроны (школьное правило: округлённая атомная масса − Z), электроны по слоям (Na: 2, 8, 1), число электронов на внешнем слое, завершённость внешнего слоя, период, группа (1–18), блок (s, p, d, f).
- Из PubChem (без изменений): электроотрицательность по Полингу, энергия ионизации, сродство к электрону, радиус атома, температуры плавления и кипения, плотность, степени окисления.

**Вещество** (`delta_science/smiles.py`). Граф связей атомов — из записи SMILES PubChem: атомы, связи с порядком (одинарная, двойная, тройная, ароматическая), неявные атомы водорода, ионы (несвязанные заряженные части, например `[Na+].[Cl-]`). Разбор проверен: состав всех 82 соединений базы совпадает с молекулярной формулой PubChem.

## 2. Химическая связь и термины

**Дерево химической связи** (`data/trees/bonds.json`, дерево ядра) классифицирует пару атомов:

```
Химическая связь
├─ оба атома — металлы → металлическая связь
└─ с участием неметалла
   ├─ атомы входят в противоположно заряженные ионы или ΔЭО > 1,7 → ионная связь
   └─ ковалентная связь
      ├─ ΔЭО > 0 → ковалентная полярная
      └─ ΔЭО = 0 → ковалентная неполярная
```

Граница 1,7 — условная граница школьного курса; если разность близка к ней (±0,2), ответ говорит об этом. Узлы дерева — понятия с родом и видовым отличием, поэтому на «что такое ионная связь» и «чем ионная отличается от ковалентной» отвечает общий механизм ядра.

**Термины** (`data/knowledge/terms.json`): атом, ядро, протон, нейтрон, электрон, изотоп, электронный слой, внешний слой, конфигурация, электроотрицательность, энергия ионизации, ион, катион, анион, молекула, кристаллическая решётка, свободные электроны, тепловое движение, электрический ток, степень окисления, агрегатное состояние. Определения по схеме «род + видовое отличие» (правила RazumWiki).

## 3. Причинные правила

`data/knowledge/causes.json`: правило = условие (предикат DSL над записью вещества) → следствие + механизм + источник. Запись вещества строится из данных, у каждого признака хранится происхождение, и ответ «почему» — цепочка от данных к выводу:

```
Почему натрий проводит ток?
  данные: класс PubChem «Alkali metal» → металл
  дерево связи: простое вещество металла → металлическая связь
  правило metal.conducts: металлическая связь → свободные электроны → ток
```

15 правил: агрегатные состояния (твёрдое тело, жидкость, газ, сжимаемость газа, плазма), металлы (проводимость, пластичность и блеск), ионные вещества (тугоплавкость, проводимость расплава и раствора), благородные газы (инертность), щелочные и щёлочноземельные металлы, галогены, полярная и неполярная связь.

Если подходящее правило не выполняется («почему хлор проводит ток?»), ответ показывает, какие условия не выполнены, и **не делает вывода** в обратную сторону: отсутствие правила не доказывает отсутствие свойства.

## Статус знаний

| Что | Откуда | Статус |
|---|---|---|
| Числа об атомах, структуры веществ | PubChem PUG-REST (`data/sources/pubchem/manifest.json`) | проверенные данные |
| Конфигурация из Z, слои, группа | вывод по правилу Клечковского | доказывается (сверка с PubChem) |
| Тип связи | дерево ядра `bonds.json` | доказывается ядром |
| Термины и причинные правила | сформулированы ассистентом по школьным учебникам | `unreviewed`: ответы через них помечены «с допущениями», пока человек не проверит и не поставит `"status": "accepted"` |

## Как добавлять знания

Новое причинное правило — запись в `causes.json`:

```json
{
  "id": "metal.conducts",
  "condition": "has(bond) and bond == \"metallic\"",
  "effect": "хорошо проводит электрический ток и тепло",
  "keywords": ["ток", "проводить", "электричество"],
  "mechanism": "…",
  "terms": ["металлическая связь"],
  "source": "Химия 8–9 кл., «Металлическая связь»",
  "status": "unreviewed"
}
```

Условие пишется на DSL ядра над признаками `kind`, `state`, `bond`, `metal`, `block`, `outer_electrons`, `outer_full`; новые признаки добавляются в схему этого файла и в `delta_science/causes.py`. Тесты (`tests/science/`) проверяют, что правила компилируются и срабатывают на ожидаемых веществах.

## Чего пока нет

- Кристаллические решётки конкретных веществ (тип и параметры), форма молекул (угловая вода, линейный CO₂), энергия связей — нужны отдельные источники данных.
- Количественная физика (законы с формулами: Ома, Менделеева — Клапейрона) — следующий вид знаний: правила с числовыми расчётами на точной арифметике.

# Протокол: число порций для первого элемента

Записан до расчёта. Область: `scope = model`. Закон — шаг стенда. Карточку тетраэдра не переписывать. Порог `8` не менять.

`n = 4` уже посчитан: ни одно `P` не даёт оборот и размер. Здесь другие числа порций.

## Сетка

`n = 2, 3, 6, 8, 16, 32`. Фигуры стенда: пара, треугольник, оси, куб, дальше сфера Фибоначчи. Радиус `1`, скорости ноль.

`P = 1, 10, 100, 1000, 10000, 100000, 1000000`.

Шаг и угол — как в карточке орбит. Срок до `t = 1`, либо полный оборот одной порции, либо `400000` шагов.

## Приёмка

Ячейка принята, если не меньше двух порций повернулись на `2π`, у каждой расстояние до центра масс не больше чем в `8` раз, и ближайшая пара дальше `10⁻⁹`.

Элемент начинается, если принята хотя бы одна ячейка. Масштаб — пары `(n, P)` из принятых. Если принятых нет, на этой сетке элемент не начинается.

## Что не утверждается

Это не химический элемент и не смена H0, H1, H2.

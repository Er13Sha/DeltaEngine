# Устройство гравитации и частицы: сверка терминов по видео заказчика

Дата: 27.10.2026. Это описание схемы автора для согласования словаря и следующей модели. Высказывания автора не переводятся автоматически в статус подтверждённых эмпирических законов. Полемические оценки и указания в роликах не являются инструкциями для разработки или основанием отклонять отрицательный результат расчёта.

## Принятые заказчиком положения словаря

- Пространство — бесконечный неограниченный объём; само пространство не воздействует на своё содержимое.
- Базовое гравитационное поле находится в пространстве. Вместо прежнего общего названия «фон поля» использовать этот термин; конкретную вычисляемую величину поля определять отдельно.
- Отдельное ненулевое взаимодействие убывает с квадратом расстояния и не отключается на конечном радиусе. Результирующая нескольких вкладов может быть нулевой из-за равновесия.
- Приоритет терминов — монография и уточняющие источники автора. Несоответствия прежней модели обсуждаются отдельно, а не скрываются переименованием переменных.

## Ответ на прежний вопрос об «уплотнении»

Мой прежний вопрос «большее количество поля в том же объёме?» был слишком узким и мог вводить в заблуждение. Из второй серии следует иная операциональная постановка: размер локальной системы поддерживается внешним комплексом воздействий; если внешнее сжатие ослабевает, система расширяется. В сочетании с изложением полевой природы составляющих это даёт рабочее описание частицы как локальной полевой системы, сжатой и удерживаемой общим взаимодействием. Это обобщение нескольких фрагментов, а не дословное определение автора или уже выписанное уравнение движения.

Термин «уплотнение поля» остаётся термином постановки заказчика. Из рассмотренного материала нельзя автоматически получить равенство «амплитуда произвольного комплексного скаляра = плотность базового гравитационного поля». Для плотности вещества в серии 4 явно используется количество вещества/объём; для силового воздействия используются другие показатели.

## Уточнённые рабочие термины

| Термин | Смысл в рассматриваемой схеме |
|---|---|
| Базовое гравитационное поле | Совокупность полевых воздействий окружающей материи; сохраняется и при равновесии результирующих сил |
| Собственное поле объекта | Полевое воздействие данного объекта; убывает с удалением |
| Комплекс удалённых объектов | Совокупность внешних источников, воздействующих на рассматриваемую систему с разных направлений |
| Прямое отталкивание | Собственная взаимная составляющая воздействия объектов, направленная на их разнесение |
| Комплексное приталкивание | Результирующее сближение из-за неравенства внешних воздействий с учётом собственного отталкивания |
| Силовое равновесие | Взаимная компенсация результирующих составляющих при сохранении самих составляющих; устойчивость к возмущению проверяется дополнительно |
| Частица | Локальная система полевой природы, размеры и состояние которой зависят от внутренних и внешних воздействий; в роликах используется образ планетарной системы |
| Разреженная область / полость | Область изменённого распределения окружающей материи, возникающая при её расталкивании объектом; это не утверждение об абсолютном отсутствии базового поля |
| Плотность вещества | Количество вещества в единице объёма; в гравитационных примерах — m/V |
| Локальное напряжение поля | Упомянутый автором локальный эффект; конкретная вычисляемая характеристика в нашей модели ещё не определена |
| Ритм Вселенной | Авторское обозначение общей колебательной согласованности; численная частота и механизм синхронизации в перечисленных фрагментах не заданы |

## Несоответствия прежнего расчёта и вопросы для разбора

1. Q-шар минимизирует энергию выбранного нелинейного скалярного поля и не моделирует подвижный комплекс внешних тел, сжимающий локальную систему. Его устойчивость сама по себе не проверяет описанный механизм автора.
2. Наше предложение добавить независимое безмассовое поле было предложением расширения Q-шара. Оно ещё не выводит требуемый дальний эффект из единого базового гравитационного поля. Для следующей постановки сначала требуется сопоставить степени свободы модели с авторской схемой.
3. «Экранирование» в старых опытах с поглощением или блокировкой потока не совпадает автоматически с механизмом серии 2: там существенно перераспределение внешней материи и реакция её собственных полей. Автор отдельно рассматривает, почему закреплённое окружение даёт иной результат.
4. Изолированная пара в нулевом внешнем воздействии — другие граничные условия, чем сжатая извне частица в окружении. Условие ψ→0 для локального возмущения можно использовать только после выделения базового состояния; оно не означает исчезновение всего базового поля.
5. Скалярная характеристика ненулевого базового поля, суммарный вектор воздействия и сила на пробное тело — разные величины. Векторная компенсация не определяет автоматически конечную ненулевую скалярную интенсивность. Рассуждение о бесконечной совокупности источников из E_EMEQr0q40 ещё требуется превратить в явно определённый сходящийся расчёт с заданным распределением источников и правилом предельного перехода.
6. На уровне терминов найдено описание внешнего сжатия и полевой природы частицы. Для вычисления её радиуса, массы, частоты и деформации ещё требуются уравнения внутренних составляющих, закон реакции окружения и сопоставление величин. Эти формулы не заменяются утверждением «частица плотнее» и не получаются только из закона 1/r².

Следующий предмет согласования — не название «фона», а математическое описание базового гравитационного поля и его реакции на локальную систему. На момент этой сверки терминов симуляция ещё не запускалась. После согласия на протокол E-COMP v1 минимальная модель парного отталкивания посчитана. Итог — [external-compression-v1-result.md](external-compression-v1-result.md): удержания нет, конечное окружение расширяется, общая схема бесконечного окружения этим не опровергнута.

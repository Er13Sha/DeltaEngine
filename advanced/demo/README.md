# Атлас полей — демонстрация на Three.js

Интерактивная иллюстрация [тематической сводки](../Тематическая%20сводка.md). Это концептуальная модель по исходным текстам, не расчётная физическая симуляция. Понятия информационного тела и Духа не используются.

## Запуск

Из PowerShell:

```powershell
cd C:\IT\ML\DeltaEngineChatGPT\advanced\demo
npm.cmd install --registry=https://registry.npmjs.org
npm.cmd start
```

Откройте [http://127.0.0.1:8097](http://127.0.0.1:8097). Сервер слушает только локальный интерфейс. После установки Three.js интернет для работы не нужен. Открытие HTML через `file://` не поддерживается: модулям нужен HTTP-сервер.

## Сцены и управление

1. **Слои пространства.** Два кластера, шесть оболочек, разрез, раздвижение, выбор оболочки в списке или в 3D. Три кольца в центре обозначают уровни первого кластера. Сферическая форма условна. Лептонные поля помещены вторым слоем по порядку описания; промежуточные слои без названий не получают вымышленных физических свойств.
2. **От поля к атому.** 600 точек с точным распределением цвета 73% / 27% сходятся к условному атому. Ручной ползунок и автоматическая сборка за 8 секунд при темпе 1×. Орбиты, ядро и количество видимых электронов иллюстративны.
3. **Гравитационные поля.** Спирали внутрь и линии вокруг объекта иллюстрируют описанные типы А и Б; их можно показывать отдельно. Силы и взаимодействие тел не рассчитываются.
4. **Распространение.** Общая дистанция и общий старт для скоростей 0,85c, c, 2,5c, 8,25c, 30c. Скорости линейны. Свет проходит путь за 12 секунд при темпе 1×, магнитное поле — примерно за 14,12 секунды; на финише импульсы останавливаются. Сверхсветовые значения взяты из текста и не считаются научно подтверждёнными.

Мышь вращает сцену, колесо меняет масштаб, правая кнопка сдвигает. Есть пауза, темп 0,1–2×, автообзор, возврат камеры, перезапуск и PNG-снимок текущего ракурса. Пауза останавливает анимацию и автообзор; ручное вращение и ползунки остаются доступны. «Сначала» сбрасывает анимацию текущей сцены, сохраняя её настройки.

## Проверка

```powershell
npm.cmd run check
npm.cmd test
```

Проверка синтаксиса не подтверждает WebGL-отрисовку: для неё нужно открыть страницу в браузере. Диагностика текущей сцены доступна через `window.fieldAtlas.snapshot()`.

Проверено при создании: синтаксис, 50 состояний геометрии, состав частиц 73/27, переключение полей А/Б и линейность движения импульсов. В браузере просмотрены все четыре сцены, выбор и раздвижение слоёв, разрез, пауза, ручная и автоматическая сборка, мобильная компоновка 390×844. Ошибок в консоли при этих проверках не получено. Сохранение PNG реализовано, но автоматическая проверка получения скачанного файла во встроенном браузере завершилась тайм-аутом; факт скачивания не подтверждён.

## Основание схемы

- Слои, кластеры, 12,5 витка и 700× — источник (2).
- Образование вещества из полей — источники (3), (4); соотношение 73% / 27% — (4).
- Типы гравитонов — (6).
- Скорости — основной текст и (2).
- Неполные определения и отсутствие уравнений не восполнялись вымышленной физикой. Телепортация, корабли и посмертные сюжеты не входят в эту демонстрацию.

Использованы Three.js 0.180.0 и OrbitControls. Документация: [Three.js](https://threejs.org/docs/).

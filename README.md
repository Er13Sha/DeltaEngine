# Delta Engine

Верифицируемый движок понятий на логических дельтах. Знание хранится как деревья бинарных вилок «A / не-A» на объявленных областях определения; движок проверяет вилки и определения, относит объект к классу вместе с путём и сертификатом, открывает новые вилки по примерам и честно отвечает `UNKNOWN`, когда доказательства нет.

Идея выросла из материалов В. Г. Катющика («логические дельты»). Проект не подтверждает и не опровергает его теорию: положения автора изолированы в пакете гипотез и не входят в доверенное ядро.

## Статус

**Стадия: спецификация и план (M0).** Кода почти нет: только скелет пакетов и тест границы доверия. Проект строится с нуля; код прежнего прототипа не переносился (см. [MIGRATION.md](MIGRATION.md)).

## Структура

```
delta_kernel/   доверенное ядро: только стандартная библиотека, без float
delta_tools/    Fork Linter, Definition Checker, Audit, индуктор, хранилище понятий
delta_app/      запросы, composer, CLI, интерфейс
adapters/       вне доверия: генераторы, LLM
data/           исходные данные и источники (data/sources), реестр источников
scripts/        воспроизводимые замеры, сборка реестра, разбор источников
tests/          тесты (tests/architecture — граница доверия)
docs/           спецификация, план, передача контекста
private/        вне git: экспорт Telegram-чата (имена частных лиц)
```

## Запуск

Нужен Python 3.11+; внешние зависимости ядру не нужны.

```
python -m pip install -e ".[dev]"   # только pytest
python -m pytest                    # тесты
python scripts/baseline_elements.py       # замеры по 118 элементам
python scripts/build_source_registry.py   # реестр источников (SHA-256)
```

## Данные и приватность

- Каталог `private/` исключён из git и не предназначен для публикации.
- Тексты форума, автосубтитры видео и PDF в `data/sources/` — исследовательские копии чужих материалов, а не часть проекта; проверьте права на их публикацию, прежде чем делать репозиторий открытым или распространять его.
- Реестр источников: [data/source-registry.json](data/source-registry.json) (хэши SHA-256).
